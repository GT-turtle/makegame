# 배낭공방: 내 영지

안드로이드 가로 화면과 폴더블을 지원하는 오프라인 영지 개척·실시간 부대 원정 RPG 프로토타입입니다.

## 핵심 목표

- 내 영지에서 `대륙 전체 → 지역 확대 → 하위 필드 → 광산·동굴·던전` 순서로 지도를 확대하고 41×41 필드를 첫 터치 위치에 생성되는 조이스틱으로 탐사
- 각 개척권을 안전·주의·위험 거점으로 나누고 선행 지역을 점령해 개방
- 생활권·원정대·생태·물류·외교·보고는 지도 양쪽 접이식 메뉴에서 관리
- 비점령 필드에서 던전 진입 전까지 이동 거리에 따라 발생하는 불규칙 습격
- 필드 좌표에 놓인 부락지에 직접 들어가 생활권 후보지 발견
- 여러 원정대를 구성해 점령지를 자동 탐사·토벌하고 던전·광맥·약초밭을 확률 발견
- 점령지와 별도인 생활권에 주민을 두고, 발견 작업지에 인력을 파견해 호위 수송대로 생산물을 영지까지 운반
- 생활권이 아닌 점령지를 안전 4·주의 3·위험 2주기마다 토벌하고 방치 불이익 관리
- 현지 영주와 조우해 물물교환·정찰·이간 공작·개척 압박을 선택하고 민심과 보복 위험 관리
- 필드의 실제 입구 좌표에서 15×15 밀집 던전으로 진입
- 직접 조작하는 개척자 1명과 스스로 이동·대상을 선정하는 자동 동료 최대 2명의 실시간 전투
- 플레이어 뒤에서 바라보는 후방 시점 전투, 카메라 기준 조이스틱 이동, 자동 조준 공격·회피와 장착 기술 3개를 직접 조작
- 기본 직업 고유 패시브는 유지하면서 전승 패시브와 액티브 5개가 추가로 바뀌는 전승 직업 체계
- 가방에 놓인 모든 아이템의 조건부 연쇄 발동
- 아이템의 위치·방향·인접 관계를 이용한 빌드 최적화
- 창고 물품을 장비·광석·특수·기타로 구분하고 Cu·Fe·Al·Sn·Ti 금속 자원을 지역별 광산에서 채굴
- 크루세이더 `수호의 순환`, 네크로맨서 `영혼 수확` 기본 패시브와 전승별 변형 기술 숙련도
- 자동 성장하는 힘·민첩·지능·방어력과 신성·자연 친화도. 상태 저항은 크루세이더, 치명타는 향후 지정 직업에만 개방
- 부패·독·출혈·기절·빙결·화상 6종 상태이상과 크루세이더 1번 기술의 해제
- 고블린·오크·늑대·곰 네 기본종에 북·남·동·서·중부 전투 특성을 입힌 지역 변종
- 다섯 지역 전용 확대 지도와 전투 배경, 두 전승 직업·다섯 지역 동료·네 기본 몬스터의 회화풍 전투 원화
- 기온·독성·한기·오염에 장비, 특성, 연금, 기술로 대응
- 원정 재료와 설계도를 가져와 일꾼이 있는 영지에서 장비 제작
- 지역마다 3명씩 총 15명의 고유 유닛, 지역 출신과 교체 가능한 보조 특성
- 개척 위협도가 쌓이면 발생하는 동·서·남·북 네 성문 PvE 수성전
- 성문마다 최대 10명의 고정 수비대를 배치하고, 개척자와 자동 동료 2명의 기동대로 전장을 오가며 지원
- 성문이 무너지면 영지 내부전장으로 후퇴해 결전을 치르고, 승리 뒤에도 별도 부대로 잔당 소탕
- 영지 전경의 건물을 직접 눌러 고용·연구·제작·가방·원정 시설 이용

## 실행

이 컴퓨터에서는 [PLAY_PROTOTYPE.cmd](./PLAY_PROTOTYPE.cmd)를 실행하면 브라우저가 자동으로 열립니다.

Node.js가 있는 환경에서 다음 명령을 실행합니다.

```text
node scripts/serve.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

같은 와이파이의 Android 기기에서 시험하려면 `node scripts/serve.mjs --lan`으로 실행한 뒤, 휴대폰 브라우저에서 `http://컴퓨터의-IP:4173`으로 접속합니다. 처음 연결할 때 Windows 방화벽 허용이 필요할 수 있습니다.

## 조작

- 첫 화면은 항상 `내 영지`입니다. `원정 성문`을 누르면 다섯 개척권의 전체 지도가, 지역을 누르면 안전·주의·위험으로 나뉜 확대 지도가 열립니다.
- 대륙·지역 지도는 `＋/−` 버튼 또는 두 손가락 벌리기·오므리기로 확대·축소합니다. 대륙에서 확대하면 지역 지도, 지역에서 확대하면 선택한 하위 필드로 들어갑니다.
- 확대 지도에서 거점 필드를 누르면 광산·동굴·던전·약초밭이 놓인 하위 지도가 열립니다. 중앙 원정 거점에서 점령 전에는 `필드 진입·점령`, 점령 후에는 `필드 토벌 출정`을 선택합니다.
- 미확인 장소는 점령·토벌 원정 또는 자동 탐사를 통해 종류와 품질이 드러납니다. 작업지는 생활권 인력을 보내 개발하고 전투 장소는 직접 탐험할 수 있습니다.
- 생활권·원정대·생태는 왼쪽, 물류·외교·보고는 오른쪽 메뉴에서 열어 지도를 가리지 않고 설정합니다.
- 첫 안전 구역을 점령하면 인접 구역이 열립니다. 점령은 통행권과 치안 확보이며 자동 정착을 뜻하지 않습니다.
- 주민은 내 영지 또는 별도로 조성한 지역 생활권에서 살고, 광맥·약초밭·벌목지에는 작업자로 파견됩니다. `개척 주기 진행` 때 생산품이 이동하며, 호위와 수송로가 부족하면 약탈됩니다.
- 현지 문명과 처음 조우한 뒤 물물교환, 정보 정찰, 민심을 흔드는 이간, 보복군을 부르는 개척 압박을 시험할 수 있습니다.
- 영주관·고용소·룬 공방·대장간·창고는 전경의 건물이나 아래 바로가기를 눌러 이용합니다.
- 창고에서는 `장비 / 광석 / 특수 / 기타` 탭으로 물품을 확인합니다. 장비만 원정 가방에 배치하며 광석·특수·기타 물자는 영지 제작과 개발에 사용합니다.
- 일반 광산은 지역에 따라 구리(Cu)·철(Fe)·알루미늄(Al)·주석(Sn)·티타늄(Ti) 광석을 생산합니다. 룬 조각·약재·마석은 특수 물품으로 따로 관리합니다.
- 필드는 41×41입니다. 화면 왼쪽 영역을 처음 누른 자리에 조이스틱이 생기며, 누른 채 밀어 한 칸씩 이동합니다. `지역 지도`에서는 밝혀진 먼 타일을 눌러 장거리 경로를 지정합니다.
- 비점령지의 점령 원정에서는 던전에 들어가기 전까지 이동 중 불규칙 습격을 받을 수 있습니다. 고정된 `!` 표식과 별도로 발생합니다.
- `▤` 부락 타일에 도착해 안으로 들어가면 해당 지역 생활권 후보지가 기록됩니다. 구역을 점령한 뒤에도 부락을 발견해야 촌락을 조성할 수 있습니다.
- 생활권이 아닌 점령지는 지도에 표시된 토벌 기한 안에 직접 재토벌하거나 자동 원정대를 보내야 합니다. 방치하면 위협과 약탈 위험이 오르고 장기 방치 시 작업지 수득량이 감소합니다.
- 필드에 흩어진 `!` 몬스터 무리나 불규칙 습격과 조우하면 전투 시작 확인창에서 시간이 멈춥니다. 확인한 뒤에만 실시간 전투가 시작됩니다.
- 전투에서는 플레이어 뒤쪽 카메라로 개척자를 직접 조작하고 편성한 최대 2명의 동료가 자동으로 싸웁니다. 왼쪽에서 처음 누른 자리에 생기는 조이스틱으로 이동하고 화면을 드래그해 시야를 돌리며, 오른쪽의 `공격`, `회피`, 장착한 전승 기술 3개를 사용합니다. 공격은 가까운 적을 자동 조준하고 카메라를 목표 방향으로 맞춥니다.
- 전투가 끝나면 1초 동안 전장을 멈춰 보여준 뒤 결과창을 띄우며, 결과 확인 전에는 필드 이동을 재개할 수 없습니다.
- 영주관에서 `정령 크루세이더` 또는 `중병기 네크로맨서` 전승을 선택할 수 있습니다. 기본 직업 패시브 1개는 항상 유지되고, 전승 패시브 1개와 액티브 5개가 추가됩니다. 출정 전 액티브 3개를 장착합니다.
- 정령 크루세이더의 `정령의 치유`는 가장 다친 아군을 회복하고 지속 회복과 해로운 효과 1개 해제를 함께 적용합니다. `서리 수호진`, `성화 폭발`, `뇌정의 창`, `폭풍의 심판`으로 상태와 위치를 제어합니다.
- 중병기 네크로맨서는 현재 전투에서 죽은 일반 적을 최대 3기까지 무장 부활시킵니다. 고블린은 중검, 오크는 망치, 늑대는 철제 이빨, 곰은 철제 발톱 오버레이를 사용합니다. 지역 우두머리를 정복하면 마지막 한 마리의 봉인 정보가 저장됩니다.
- 영주관 또는 고용소에서 부대를 편성하고, 유닛을 훈련하거나 다른 지역의 보조 특성을 부여할 수 있습니다.
- 원정과 개척으로 위협도가 쌓이면 내 영지 수성전이 예고됩니다. 전투 전 각 성문에 권장 5명·최대 10명의 수비대를 배치하고 잔당 소탕조도 정합니다.
- 수성전에서는 개척자와 자동 동료 2명이 동·서·남·북 성문을 오가며 지원합니다. 지원하지 않는 문도 고정 수비대와 민병대가 동시에 버티며, 내구도가 0이 되면 내부전장으로 이어집니다.
- 주력군을 막은 뒤에는 배치한 소탕조의 전투력으로 성내 잔당을 정리합니다. 게임을 꺼둔 동안 성문이나 건물이 자동 파괴되지는 않습니다.
- 필드 깊숙한 던전 표식에 도달하면 15×15의 좁은 던전으로 들어갈 수 있습니다. 던전에는 수문대 둘과 지역 우두머리가 있습니다.
- `지역 지도`에서 발견 영역, 몬스터, 던전 입구와 정리한 위치를 확인하고 먼 지점을 목적지로 지정할 수 있습니다.
- 개척자는 동료와 별개로 항상 전투에 참여하며 원정 경험치로 성장합니다.
- 가방에서는 아이템을 선택한 뒤 빈 칸을 눌러 옮깁니다.
- 영지의 벌목꾼·광부·대장장이는 원정 성과에 맞춰 자동 생산을 진행합니다.
- 공방에서는 설계도와 재료를 사용해 품질과 옵션이 다른 장비를 제작합니다.
- 안드로이드 뒤로가기는 가방 → 원정 화면 → 공방 순서로 이동하며 진행 중인 원정은 보존합니다.

진행 상황은 브라우저의 로컬 저장소에 자동 저장됩니다.

## 프로토타입 범위

- 지역을 구분해 선택하는 터치형 전체 대륙 지도
- 지역마다 독립 생성되는 41×41 필드와 11×11 추적 카메라
- 필드 좌표에 배치된 몬스터 조우, 랜드마크와 던전 입구
- 15×15 밀집 던전, 두 수문대와 지역 우두머리
- 다섯 지역, 15개 동료 데이터, 배치 순서 보정이 없는 최대 2인 동행 편성
- 유닛 레벨과 경험치, 지역 정복 동료 합류, 교체 가능한 보조 특성 9종
- 플레이어 직접 이동·적 지정·기본 공격·회피·장착 기술 3개
- 플레이어 1명과 자동 동료 최대 2명이 동시에 참여하는 전투
- 전장 좌표를 카메라 기준으로 원근 투영하는 후방 시점 전투장, 지역별 원화 배경·전신 전투 인물과 우측 상단 미니 레이더
- 기본 직업 2종의 고유 패시브, 전승 직업 2종의 추가 패시브·액티브 5개·3칸 장착, 자동 성장 스탯·친화도와 기술 숙련도
- 6종 상태이상, 상태 아이콘·중첩 표시, 회전 뼈 방패와 종별 소환 무기 오버레이
- 고블린·오크·늑대·곰 4개 기본종과 다섯 지역 변종·우두머리
- 지역별 환경 압력 4종과 여러 대응 조합
- 19종 아이템, 공간 조합, 제작 품질·무작위 옵션
- 장비·광석·특수·기타 4분류, 5종의 기초 금속 광석, 지역 특산물과 자동 생산
- 개척 위협도, 성문별 5~10명 배치, 기동대 전환, 성문 내구도, 내부전장과 잔당 소탕
- 세부 개척 구역 17곳, 현지 세력 5곳, 광산·동굴·던전을 포함한 발견 거점 11종
- 직접 제1원정대와 자동 제2·제3원정대, 주민 개발·물류·호위·약탈품 회수
- 영지 만족도와 현지 세력의 신뢰·경계·민심·불안·첩보 수치
- 연구 6종과 v1~v17 저장 호환
- Android `sensorLandscape` 가로 고정과 폴더블 가로 화면 대응
- PWA 오프라인 캐시

## 시각 자산

- 대륙·지역·하위 필드와 내 영지는 별도 원화 위에 터치 노드를 겹쳐 표시하므로, 그림을 바꿔도 기능과 진행 데이터는 유지됩니다.
- 지역 확대 지도와 전투장은 북부 설산·남부 우림·동부 산악·서부 제후국·중부 사막 전용 배경을 사용합니다.
- 플레이어 직업은 밝고 선명한 한국 웹툰풍 투명 전신 그림을 사용하며, 현재 정령 크루세이더에 먼저 적용됩니다. 동료와 고블린·오크·늑대·곰은 회화풍 투명 아틀라스로 표시하고 작은 화면에서는 모두 자동으로 크기가 줄어듭니다.

상세한 방향과 확장 순서는 [게임 설계서](./docs/GAME_DESIGN.md)에, 참고작에서 가져올 원칙과 피할 점은 [벤치마크 분석](./docs/BENCHMARK_ANALYSIS.md)에 정리되어 있습니다.
