# 배낭공방: 폐역 원정

안드로이드 세로 화면을 우선으로 만든 오프라인 영지 개척·턴제 원정 RPG 프로토타입입니다.

## 핵심 목표

- 직접 이동하고 적의 예고 공격에 대응하는 턴제 탐험
- 가방에 놓인 모든 아이템의 조건부 연쇄 발동
- 아이템의 위치·방향·인접 관계를 이용한 빌드 최적화
- 기사·야만인·메카닉·무인의 직업 기술과 영구 숙련도
- 기온·독성·한기·오염에 장비, 특성, 연금, 기술로 대응
- 원정 재료와 설계도를 가져와 일꾼이 있는 영지에서 장비 제작

## 실행

이 컴퓨터에서는 [PLAY_PROTOTYPE.cmd](./PLAY_PROTOTYPE.cmd)를 실행하면 브라우저가 자동으로 열립니다.

Node.js가 있는 환경에서 다음 명령을 실행합니다.

```text
node scripts/serve.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

같은 와이파이의 Android 기기에서 시험하려면 `node scripts/serve.mjs --lan`으로 실행한 뒤, 휴대폰 브라우저에서 `http://컴퓨터의-IP:4173`으로 접속합니다. 처음 연결할 때 Windows 방화벽 허용이 필요할 수 있습니다.

## 조작

- 지도에서 밝혀진 길을 누르면 캐릭터가 그곳까지 안전 경로를 따라 턴 단위로 이동합니다.
- 이동 경로에 벽·확인된 위험물이 있으면 우회하며, 새 적을 발견하면 한 턴 경계한 뒤 자동으로 이동을 재개합니다.
- 길을 적이 막고 있으면 조합한 가방 효과로 자동 전투한 뒤 원래 목적지를 향해 계속 이동합니다.
- `지도`에서 발견한 전체 지역을 확인하고 밝혀진 먼 칸을 바로 목적지로 지정할 수 있습니다.
- 적을 누르면 접근한 뒤 한 번 공격하고 멈춥니다. 가까운 칸을 누르면 한 칸씩 정밀하게 움직일 수 있습니다.
- 적 머리 위 `!`는 다음 턴 공격 예고입니다.
- 중앙 직업 기술 버튼은 공격·이동·방어로 모은 직업 자원을 소비합니다.
- 지역 환경 압력이 한계에 닿으면 피해를 받습니다. 직업·출신·가방 장비의 대응 수치가 압력 발생량을 줄입니다.
- 가방에서는 아이템을 선택한 뒤 빈 칸을 눌러 옮깁니다.
- 전투 화면에서 배치를 바꾸면 한 턴이 흐릅니다.
- 원정 턴이 흐르는 동안 영지의 벌목꾼·광부·대장장이도 자동 생산합니다.
- 공방에서는 설계도와 재료를 사용해 품질과 옵션이 다른 장비를 제작합니다.
- 안드로이드 뒤로가기는 가방 → 원정 화면 → 공방 순서로 이동하며 진행 중인 원정은 보존합니다.

진행 상황은 브라우저의 로컬 저장소에 자동 저장됩니다.

## 프로토타입 범위

- 네 지역이 연결된 31×31 연속 필드와 추적 카메라
- 목적지 터치 이동, 경로 표시, 적 발견 시 한 턴 경계 후 자동 재개
- 발견 영역을 보여주고 장거리 목적지를 지정하는 전체 지도
- 측량탑 세 곳, 야영지, 보급함, 환경 위험과 최종 감시자
- 절차 생성 지형과 적 공격 예고
- 직업 4종, 출신 특성 4종, 기술 숙련도
- 지역별 환경 압력 4종과 여러 대응 조합
- 19종 아이템, 공간 조합, 제작 품질·무작위 옵션
- 재료 7종, 설계도 12종, 일꾼 고용과 자동 생산
- 연구 6종과 v1~v3 저장 호환
- 세로형 Android 화면 대응
- PWA 오프라인 캐시

상세한 방향과 확장 순서는 [게임 설계서](./docs/GAME_DESIGN.md)에 정리되어 있습니다.
