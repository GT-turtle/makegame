기본 몬스터
- 포유류 : 곰, 늑대
- 인간형 : 고블린, 오크
- 벌레형 : 말벌(독 부여, 남부/전역), 거미(치유감소 부여, 남부, 확정), 불개미(화상 부여, 중부, 확정), 왕지네(출혈 부여, 동부, 확정)
- 절지동물 후보(추후 추가 예정) : 전갈 - 마비/기절 계열
- 반려된 후보 : 진드기(메커니즘 과도하게 복잡), 울버린(곰·오크로 대체 가능)

각 지역 카운터 표기("인간형 >> 벌레형 > 포유류" 등)는 종족 상성이 아니라 그 지역 조우의 종족 구성 비율을 뜻함.

바바리안 카운터 (남부, 확정)
- 거미: 남부에 배치. 물리면 치유감소 디버프 부여 (바바리안의 "체력 낮을수록 강해짐 + 광폭화 흡혈" 사이클을 무력화하되 즉사시키진 않음)
- 처형(즉사) 컨셉은 기각 — 너무 가혹해서 바바리안 자체를 기피하게 만들 위험
- 남부가 마침 공격력 룬(녹색 룬) 산출 지역이라, "공격 강화 자원은 주지만 회복은 막는" 지역 정체성이 자연스럽게 성립

서부(크루세이더 카운터)
- 인간형 >> 벌레형 > 포유류
- 마법을 쓰는 인간형, 높은 데미지와 낮은 공격속도, 방어력 무시 데미지

동부(매화 카운터)
- 인간형 >> 포유류 > 벌레형
- **동부에는 별도 환경 디버프를 두지 않고, 몬스터 자체가 상태이상 해제/정화 스킬을 보유**하는 방향으로 확정
- 왕지네: 벌레형 비중은 낮지만 등장하면 강한 출혈을 남기는 희귀 개체

남부(추적자 + 바바리안 카운터)
- 벌레형 >> 인간형 >> 포유류
- 개체수 많음, 공방체 낮음
- 상태이상 부여 공격 보유(거미의 치유감소 포함), 일부 네임드 인간형 몬스터 등장

북부(아크메이지 카운터)
- 포유류 >> 인간형 >> 벌레형
- 개체수 적음, 공방체 높음
- 높은 마법 저항력과 방어력으로 마법사를 압박
- 지역 자체 효과는 **마나 지속 감소**. 별도의 한기/공이속 감소 환경 게이지는 사용하지 않음

중부(네크로맨서 카운터)
- 벌레형 >> 인간형 >> 포유류
- 개체수 많음, 공방체 낮음
- 다수의 벌레를 강령해도 개별 성능이 낮아 소환 효율이 떨어짐
- 고대 마도공학 기계는 시체가 남지 않아 강령 자체가 불가능
- 불개미: 떼로 몰려들며 화상을 남기는 다수 개체

추가 고려
잔몹 : 골렘(북부, 서부), 오우거, 미노타우루스, 예티(북부), 사람, 미라(누군가 조종), 강시(누군가 조종), 좀비(누군가 조종), 지네(남부, 중부), 사마귀(남부), 전갈(중부), 뱀(남부, 서부, 동부), 나방(사람처럼 생긴 군대팅커벨), 개미(많은 불개미 + 높은 공방체의 병정개미), 거북이, 모기(남부), 매머드(북부), 고릴라(킹콩), 독수리, 아르마딜로, 쥐, 소, 박쥐, 개구리(독)

몬스터 서열 : 지역보스(북부,남부,서부,동부,중부) --> 필드보스(지역 내 필드당 1마리) --> 던전보스(인던 내 보스, 기존 몹 강화형태) --> 네임드(ex. 병정개미) --> 일반

==========================
보스 구성 (확정)
==========================
보스 패턴 설계 원칙: 지역보스는 로스트아크류(즉사 패턴, 체력 구간별 페이즈 전환)로 설계하되 동료가 전멸해도 플레이어 혼자 클리어 가능해야 함. 필드보스도 패턴은 있으나 지역보스보다 훨씬 쉽게.

지역별 테마
- 북부 : 북유럽 신화 + 오크 + 곰
- 남부 : 크툴루 신화 + 거대 벌레 및 파충류
- 동부 : 영물(신수·요물)
- 서부 : 신성 제국이 몰락한 왕국 (하나로 이어지는 역사 — 원래 신성 제국이었으나 마지막 왕이 타락하며 왕국 전체가 저주받아 지금의 폐허가 됨)
- 중부 : 사막 + 페르시아·유목 문화 + 잊혀진 고대 마도공학 문명

[지역 거점 세력 - 확정, 직업 컨셉.txt "지역 부락 친목도" 시스템과 연결]
- 북부 : 몬스터 방어 영지 + 혹한 변경에 고립된 마탑. 바바리안(근접 방벽)과 아크메이지(마탑)은 성향·문화가 안 맞아 서로 못마땅해하는 "혐관"이지만, 몬스터 앞에선 협력할 수밖에 없는 실리적 동맹 관계
- 서부 : 신성 제국 잔당 세력이 자처하는 영지 — 저주받은 옛 왕국(자기 고향)을 정화·토벌하는 중
- 동부 : 문파 연맹 — 단일 세력이 아니라 여러 문파 지부로 나뉜 느슨한 연합. 영물(신수·요물) 테마와 맞물림
- 남부 : 열대 우림·늪지라 원래 사람이 살기 힘든 환경. 그래도 추적자 출신지 설정상 은둔자들의 마을 정도는 존재 — 세상을 등지고 험지로 숨어든 자들이 모인 곳
- 중부 : 소규모 부락 + 유목민 집단 + 대상·행상인 중심 분포. 사막 교역로를 따라 세력이 흩어져 있음

[필드 진행 순서 - 확정]
- 북부 : 타락한 마탑 리치 → 설원 거대 곰 → 오크 대전사 + 오크 마법사 → 지역보스 티탄
- 남부 : 거대 뱀 → 인면지주 → 어린 스타 스폰 → 지역보스 딥원
- 동부 : 구미호 → 오니 대장 → 초거대 지네 → 지역보스 동양용
- 서부 : 듀라한 → 고룡 → 서부 리치 → 지역보스 타락한 왕
- 중부 : 샌드웜 → 인공 만티코어 → 거대 골렘 → 지역보스 거신병

가장 하위인 1필드 보스는 해당 지역의 상위 필드 진행 패널티/직업 카운터에 대응할 수 있는 장신구 핵심 소재를 드랍한다. 세부 소재·제작 규칙은 `재료 컨셉.txt`와 `docs/REGION_PROGRESSION_HAZARDS.md`를 따른다.

북부 (아크메이지 카운터)
- 지역보스 : 티탄
- 1필드보스 : 타락한 마탑 리치 — 마탑에서 냉기 마법을 연구하다 타락한 법사. `빙결 마도핵`을 진행용 장신구 핵심 소재로 드랍
- 2필드보스 : 설원 거대 곰
- 3필드보스 : 오크 대전사 + 오크 마법사 — 한 전투에서 두 마리를 동시에 상대하는 2인조 필드보스

남부 (추적자·바바리안 카운터)
- 지역보스 : 딥원
- 1필드보스 : 거대 뱀 — `맹독낭`을 진행용 장신구 핵심 소재로 드랍
- 2필드보스 : 인면지주
- 3필드보스 : 어린 스타 스폰 — 딥원·크툴루 계통과 연결되는 촉수형 괴물. 물가 전장에서 육상으로 올라온 개체와 전투

동부 (매화 카운터)
- 지역보스 : 동양용 (산봉우리 지형, 패턴 회피 위주 전투)
- 1필드보스 : 구미호 — 매혹·정화 신수. 디버프를 스스로 씻어내며 `영핵`을 진행용 장신구 핵심 소재로 드랍
- 2필드보스 : 오니 대장
- 3필드보스 : 초거대 지네 — 영물, 전장을 몸으로 둘러싸는 형태
- 던전보스 : 강시를 부리는 주술사 (리치의 동부 하수인 — 강시 무리를 이끌고 등장)

서부 (크루세이더 카운터)
- 지역보스 : 타락한 왕 (신성 제국의 마지막 왕. 서약을 어겨 스스로와 왕국 전체를 저주로 물들임)
- 1필드보스 : 듀라한 — 타락한 왕의 저주받은 근위기사. `듀라한의 영혼`을 진행용 장신구 핵심 소재로 드랍
- 2필드보스 : 고룡 — 제국 멸망 후 폐허를 차지한 서양 드래곤
- 3필드보스 : 서부 리치 — 제국 시절의 사제·학자가 타락한 형태. 북부의 마탑 리치와 배경을 구분

중부 (네크로맨서 카운터)
- 지역보스 : 거신병 — 잊혀진 고대 마도공학 문명이 남긴 초거대 병기/그릇. 유적 깊은 곳에서 재가동됨
- 1필드보스 : 샌드웜 — 현재 사막의 자연 생물. `샌드웜 열핵`을 진행용 내열 장신구 핵심 소재로 드랍
- 2필드보스 : 인공 만티코어 — 고대 문명이 여러 생물의 육체·기관·마력을 결합해 페르시아 전승의 만티코어를 인공적으로 재현한 **키메라형 마도공학 병기**
- 3필드보스 : 거대 골렘 — 고대 문명의 본격적인 자동 마도공학 병기
- 던전보스 : 해체공정 중추 — 고대 폐기물 처리 지능. 전투 중 해체수집체를 계속 생산·파견하며, 기계라 처치해도 시체가 남지 않아 네크로맨서의 강령을 차단

[중부 고대 문명 몰락 방향 - 확정 골격]
- 고대 중부 문명은 마도공학으로 생명·영혼·초월적 영역까지 공학적으로 다루려 했다.
- `인공 만티코어`는 생명 합성/키메라 기술의 결과물, `거대 골렘`은 자동 병기 기술의 결과물이다.
- 기술이 발전할수록 금기에 가까워졌고, 최종적으로는 신 또는 초월적 존재의 영역을 침범했다.
- 바벨탑처럼 그 오만과 금기 침범이 문명 멸망의 직접적인 원인이 되었으며, 신/초월적 존재의 개입으로 문명이 붕괴했다는 방향을 사용한다.
- 어떤 금기를 범했는지, 거신병이 정확히 인공 신격의 그릇인지 단순 최종 병기인지는 추후 서사에서 확정한다.

지역보스 서사 구조 메모: 서부=서약을 어긴 왕 개인의 타락, 중부=문명 전체가 마도공학으로 금기를 침범한 집단적 오만. 같은 "몰락" 계열이지만 원인을 분리한다.

==========================
일반·네임드 몬스터 구성 (확정)
==========================

[일반 몬스터]
북부 : 곰, 늑대, 고블린, 홉고블린, 자이언트(오우거형) — 조우 구성은 자이언트 1마리 + (고블린 다수 or 홉고블린 다수) + 고블린 다수 식으로 짬
남부 : 고블린, 거미, 말벌, 뱀, 개구리 — 전부 실제 생물보다 더 난폭하고 흉폭하게 각색 (사실적인 생김새보다 위협적인 몬스터화)
동부 : 오니 부족, 도깨비, 호랑이, 늑대, 곰 (고블린·오크 대신)
서부 : 사람(제국 잔당 병사)이 주력, 언데드(스켈레톤 등 하급) 추가
중부 : 전갈, 지네, 곤충류 위주로 보강 (고블린·오크 대신)

[네임드 몬스터]
북부 : 예티, 매머드
남부 : 독개구리 주술사, 고블린 부족장
동부 : 이무기(아직 용이 되지 못한 거대 영물 — 지역보스 동양용으로 가는 서사적 징검다리), 오니 무사, 산군(호랑이 영물, 산의 주인)
서부 : 제국 최후의 근위대장(아직 살아있는 인간, 무너진 제국에 광신적으로 충성), 리치의 수호기사(한때 영웅이었으나 리치에게 종속된 강화 언데드)
중부 : 여왕개미, 강한 일반형 병정개미(네임드에서 강한 일반 몬스터로 격하), 해체수집체(고대 문명의 폐기물 처리·재조립 로봇 — 지금은 오작동해 뭐든 분해하려 듦. 4족보행. 기계라 처치해도 시체가 안 남아 네크로맨서의 시체 부활을 원천 차단. 아르마딜로 자리를 대체)

[크로스 리전 언데드 요소 — 확정]
- 배후 : 서부 리치(몰락한 제국의 사제·학자 출신) — 죽음을 연구하다 타락해 각지에 언데드 하수인을 심어둔 흑막
- 미라(중부) : 폐기 — 중부는 시체 없는 기계 문명(해체수집체/해체공정 중추) 컨셉으로 완전히 대체
- 강시(동부) : 강시 자체는 던전보스급 "강시를 부리는 주술사"가 등장했을 때 함께 따라나오는 부하로 격하 — 그 주술사가 리치의 하수인
- 좀비 : 별도 종으로 두지 않고 "리치에게 조종당하는 언데드" 범주로 언데드 계열에 통합 (서부 언데드와 동일 계열)
