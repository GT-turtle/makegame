지역별 재료 컨셉 초안 (기후·지형 기반 배치)
구조: 지역 - 광물(→원소) / 약제 / 룬

[룬 설계 원칙 - 확정, 코드 구현 완료]
룬은 상태이상이 아니라 순수 스탯 부여(공격력/방어력/체력/공격속도/마나회복속도)로 확정. 정령 전승의 "상태이상 확정 부여"와 아예 다른 영역이라 역할이 겹치지 않는다.
지역당 1개씩 총 5개, 커맨더가 한 번에 1개만 장착 가능 (classes.js RUNE_DEFS, game.js purchaseRune/equipRune, 영주관 화면에 UI 있음).

==========================
북부 설산 (냉대·빙하·순상지 지형)
==========================
기후 근거: 스칸디나비아·캐나다·러시아 순상지처럼 한랭 지역은 오래된 철광상이 발달한다.

[광물 → 원소]
- 적철석 Hematite → 철(Fe)
- 망간자철석 Jacobsite (자철석 변종, (Mn,Fe)(Fe,Mn)2O4) → 철(Fe) + 망간(Mn, 소량)
  * 망간은 전용 원석이 없고 이런 부산물로만 얻는 희귀 촉매 원소로 설정 (실제 용도: 제철 첨가제·탈산제)

[약제]
- 로디올라 Rhodiola (고산·한대 자생) → 피로회복·고지 적응 강장제 (시베리아·스칸디나비아 전통 약재)
- 아르니카 Arnica (고산 초원) → 타박상·근육통 외용 연고

[룬]
- 룬 : 청색 --> 마나 회복 속도 증가

==========================
남부 우림 (열대·라테라이트 지형)
==========================
기후 근거: 고온다습한 열대 기후에서 라테라이트(적색풍화토)가 발달하며, 보크사이트와 망간광이 실제로 같은 라테라이트 지대에서 함께 산출된다 (기니, 브라질, 가나 등).

[광물 → 원소]
- 보크사이트 Bauxite → 알루미늄(Al)
- 연망간석 Pyrolusite (라테라이트성 망간광) → 망간(Mn)
  * 보크사이트와 화학적으로 같은 광물은 아니지만, 같은 라테라이트 광상에서 함께 채굴되는 실제 지질 조합

[약제]
- 기나나무 껍질 Cinchona bark → 말라리아 치료제 (키니네의 원료, 열대 우림의 대표 약용식물)
- 정향 Clove → 진통·방부 (치과용 진통제 전통 재료)

[룬]
- 룬 : 녹색 --> 공격력 증가

==========================
동부 산악권 (조산대·고산 지형)
==========================
기후 근거: 안데스·알프스·히말라야 같은 조산대는 주석·티타늄이 포함된 맥상 광상과 고산 약초가 함께 발달한다.

[광물 → 원소]
- 주석석 Cassiterite → 주석(Sn)
- 황석석 Stannite (Cu2FeSnS4) → 주석(Sn) + 구리(Cu) + 철(Fe) — 하나의 광물에서 3원소 동시 산출
- 금홍석 Rutile → 티타늄(Ti)
- 티탄철석 Ilmenite (FeTiO3) → 티타늄(Ti) + 철(Fe)

[약제]
- 동충하초 Cordyceps (고산 자생 버섯) → 원기회복·면역강화 보약
- 인삼 Ginseng (산악 자생) → 원기회복 보약

[룬]
- 룬 : 자색 --> 공격 속도 증가

==========================
서부 제후국 (온대·카르스트 지형)
==========================
기후 근거: 유럽 알프스·발칸·실레지아 등 온대 카르스트(석회암) 지대는 아연-납 광상의 고전적인 산지다.

[광물 → 원소]
- 섬아연석 Sphalerite (ZnS) → 아연(Zn) + 희귀 부산물 (카드뮴·인듐·갈륨 등, 실제로 아연 제련의 주요 부산물)
- 능아연석 Smithsonite → 아연(Zn)

[약제]
- 카모마일 Chamomile → 수면 유도 진정차
- 라벤더 Lavender → 항불안 아로마 오일
- 버드나무 껍질 Willow bark → 해열진통제 (아스피린 원료 성분 살리신)

[룬]
- 룬 : 황색 --> 방어력 증가

==========================
중부 사막 (건조 사막 지형)
==========================
기후 근거: 칠레 아타카마 사막이 세계 최대 구리 산지이듯, 건조 기후에서는 산화·탄산염형 구리광물이 잘 보존된다.

[광물 → 원소]
- 공작석 Malachite → 구리(Cu)
- 황동석 Chalcopyrite (CuFeS2) → 구리(Cu) + 철(Fe)

[약제]
- 알로에 Aloe vera (사막 자생 다육식물) → 화상·피부 재생 겔
- 몰약 Myrrh (사막 수지) → 방부·소염 (고대부터 쓰인 방부제)

[룬]
- 룬 : 적색 --> 체력 증가

==========================
정리: 원소 6종 요약
==========================
철(Fe) - 북부 주력, 동부·중부에서 부산물로도 산출
알루미늄(Al) - 남부 주력
주석(Sn) - 동부 주력
티타늄(Ti) - 동부 주력
아연(Zn) - 서부 주력
구리(Cu) - 중부 주력, 동부에서 부산물로도 산출
망간(Mn) - 전용 지역 없이 북부(부산물)·남부(전용 광석)에서만 소량 산출하는 희귀 촉매 원소
