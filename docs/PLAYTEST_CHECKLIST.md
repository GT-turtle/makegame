# 플레이 테스트 체크리스트

## 첫 5분

- 직업과 출신 특성의 차이를 설명 없이 이해하는가
- 원정 시작 방법을 설명 없이 찾을 수 있는가
- 원하는 칸을 누르면 이동한다는 조작을 설명 없이 이해하는가
- 표시된 경로와 적 발견 시 한 턴 경계 후 이동 재개가 신뢰감을 주는가
- 전체 지도에서 먼 목적지를 지정하는 흐름이 자연스러운가
- 적의 `!` 표시가 다음 턴 공격이라는 사실을 이해하는가
- 첫 전투에서 장검·숫돌·버클러의 발동 결과를 읽을 수 있는가

## 가방

- 아이템 선택 후 빈 칸 배치가 자연스러운가
- 회전 실패 이유를 이해할 수 있는가
- 실제 조합 관계가 시각적으로 명확한가
- 전투 중 재배치가 한 턴을 소비한다는 사실을 인지하는가
- 새 아이템을 얻었을 때 즉시 가방을 다시 짜고 싶은가

## 원정

- 탐색과 전투의 비율이 지루하지 않은가
- 9×9 카메라가 움직일 때 넓은 세계를 탐험한다는 감각이 드는가
- 네 지역의 색과 지형만 보고 현재 위치를 구분할 수 있는가
- 환경 압력의 발생량과 대응 수치를 보고 장비 교체 필요성을 이해하는가
- 직업 자원이 언제 차고 기술을 언제 쓸 수 있는지 예측할 수 있는가
- 적 공격을 피했을 때 실력으로 해결했다는 느낌이 드는가
- 보급함을 찾는 일이 충분히 기대되는가
- 야영지에서 계속 탐험할지 공방으로 돌아갈지 고민하게 되는가
- 세 측량탑을 찾은 뒤 감시자의 분지로 향할 동기가 명확한가

## 지속 성장

- 실패 후에도 다시 출발하고 싶은가
- 어떤 연구를 먼저 할지 고민이 생기는가
- 영구 성장이 단순 공격력 증가가 아니라 새 빌드 선택으로 느껴지는가
- 설계도를 찾았을 때 필요한 희귀 재료를 다시 파밍하고 싶은가
- 일꾼 고용과 자동 생산이 원정을 방해하지 않으면서 귀환 기대를 만드는가
- 무작위 품질과 옵션이 같은 장비의 재제작 동기를 만드는가

## 기록할 수치

- 첫 사망까지 걸린 시간과 턴 수
- 한 원정에서 가방을 연 횟수
- 아이템을 재배치한 횟수
- 피한 예고 공격과 맞은 예고 공격 수
- 처음 구매한 연구
- 첫 선택 직업·출신과 첫 사용 기술
- 압력 한계 피해 횟수와 대응 장비 교체 횟수
- 첫 고용 일꾼과 첫 제작 장비 품질·옵션
- 첫 승리까지 필요한 원정 횟수
