# 플레이 테스트 체크리스트

## 첫 5분

- 원정 시작 방법을 설명 없이 찾을 수 있는가
- 성문을 눌렀을 때 전체 대륙과 구분된 지역이 즉시 읽히는가
- 필드 41×41 → 던전 입구 → 던전 15×15 흐름을 출정 전에 이해하는가
- 화면 왼쪽 아래의 고정 조이스틱을 설명 없이 이동 조작으로 이해하는가
- 표시된 경로와 장애물 우회 이동이 신뢰감을 주는가
- 전체 지도에서 먼 목적지를 지정하는 흐름이 자연스러운가
- 적의 `!` 표시가 직접 조작 전투 화면으로 전환되는 조우라는 사실을 이해하는가
- 첫 전투에서 개척자는 직접 조작하고 최대 2명의 동료는 자동으로 싸운다는 사실을 이해하는가
- 영주관에서 전승별 액티브 5개 중 전투에 사용할 3개를 장착할 수 있는가
- 기본 직업 패시브와 전승 패시브가 서로 다른 효과임을 이해할 수 있는가
- 크루세이더의 5회 피격 회복 횟수와 네크로맨서 영혼 중첩·남은 시간이 전투 화면에서 확인되는가
- 신성·자연 친화도와 크루세이더 전용 상태 저항이 영주관에서 읽히는가

## 가방

- 아이템 선택 후 빈 칸 배치가 자연스러운가
- 회전 실패 이유를 이해할 수 있는가
- 실제 조합 관계가 시각적으로 명확한가
- 새 아이템을 얻었을 때 즉시 가방을 다시 짜고 싶은가

## 원정

- 탐색과 전투의 비율이 지루하지 않은가
- 11×11 카메라가 움직일 때 41×41 필드를 탐험한다는 감각이 드는가
- 북부·남부·동부·서부·중부의 색과 지역명만 보고 현재 위치를 구분할 수 있는가
- 필드에서 던전 입구를 발견했을 때 들어가고 싶은 동기가 생기는가
- 15×15 던전이 필드보다 좁고 전투 밀도가 높게 느껴지는가
- 편성 순서가 전투 성능에 영향을 주지 않는다는 점을 이해하는가
- 가로 화면에서 왼손 조이스틱 이동과 오른손 카메라 드래그를 동시에 조작할 수 있는가
- 플레이어 뒤 실루엣, 우측 상단 미니 레이더와 자동 조준 방향만으로 적 위치를 파악할 수 있는가
- 적을 누른 뒤 기본 공격을 사용해야 한다는 흐름을 이해하는가
- 회피와 장착한 전승 기술의 범위·지속시간·재사용 대기를 예측할 수 있는가
- 출혈은 긴 5중첩 피해, 화상은 짧고 강한 무중첩 피해로 체감되는가
- 크루세이더 1번 기술이 가장 다친 아군의 해로운 효과 하나를 해제하는가
- 남부 독침·서부 마법·동부 장궁·북부 대형종 고블린의 차이가 이름과 공격만으로 구분되는가
- 무장 망자 3기 제한과 우두머리 1기 저장 제한이 명확한가
- 동료가 자동으로 싸우는 동안 개척자 조작에 집중할 수 있는가

## 지속 성장

- 실패 후에도 다시 출발하고 싶은가
- 어떤 연구를 먼저 할지 고민이 생기는가
- 영구 성장이 단순 공격력 증가가 아니라 새 빌드 선택으로 느껴지는가
- 설계도를 찾았을 때 필요한 희귀 재료를 다시 파밍하고 싶은가
- 일꾼 고용과 자동 생산이 원정을 방해하지 않으면서 귀환 기대를 만드는가
- 무작위 품질과 옵션이 같은 장비의 재제작 동기를 만드는가
- 지역 정복으로 새 동료가 합류했을 때 부대를 다시 편성하고 싶은가
- 보조 특성이 유닛의 약점을 지우지 않고 새로운 운용법을 만드는가
- 위협도와 공격 예고를 보고 방어 시설·부대 편성을 점검하게 되는가
- 영지 방어 실패가 과도하게 벌주는 대신 다음 대비 동기를 만드는가

## 세부 개척과 물류

- 전체 대륙 → 세부 개척권 → 41×41 필드의 세 단계가 자연스럽게 이해되는가
- 안전·주의·위험과 선행 구역 진입 조건이 한눈에 읽히는가
- 점령 후 직접 재토벌과 자동 원정대 토벌의 차이를 이해하는가
- 탐사에서 광맥·약초밭·던전을 발견하는 순간 다음 행동이 분명한가
- 거점 개발에 필요한 주민과 재료가 부족할 때 이유를 이해하는가
- 호위가 없는 수송대의 위험과 수송로 정비 효과를 비교할 수 있는가
- 약탈품이 사라진 것이 아니라 재토벌로 회수 가능하다는 점을 이해하는가
- 현지 세력의 신뢰·경계·민심·불안이 거래와 첩보 선택에 영향을 주는가
- 개척 압박이 보복군과 내 영지 방어전으로 이어지는 인과가 납득되는가

## 기록할 수치

- 첫 조우까지 걸린 시간과 이동 칸 수
- 첫 던전 발견까지 걸린 시간
- 필드 조우와 던전 조우의 평균 간격
- 한 원정에서 가방을 연 횟수
- 아이템을 재배치한 횟수
- 기본 공격·회피·장착한 전승 기술 3개의 사용 횟수와 승률
- 전투 종료 시 유닛별 남은 체력과 피해·회복 기여도
- 선택한 2인 동행 편성과 보조 특성, 전승·장착 기술, 영지 방어 승패
- 처음 구매한 연구
- 첫 고용 일꾼과 첫 제작 장비 품질·옵션
- 첫 승리까지 필요한 원정 횟수
