# 장비·전설 장비 설계 기준

> 장비 등급, 랜덤 옵션, 특수 단조술, 전설 장비 획득·제작 방식을 정리한 기준 문서.

## 1. 장비 등급

장비 등급은 4단계로 구성한다.

- 일반
- 고급
- 희귀
- 전설

등급이 올라갈수록 기본 능력치가 조금씩 높아지고, 디아블로식 랜덤 옵션의 수와 질이 증가한다.

권장 구조:

- 일반: 기본 능력치 중심
- 고급: 기본 능력치 소폭 상승 + 랜덤 옵션 1개
- 희귀: 기본 능력치 추가 상승 + 랜덤 옵션 2~3개
- 전설: 가장 높은 기본 능력치 + 랜덤 옵션 3~4개 + 고정 고유효과

랜덤 옵션은 장비 부위별로 풀을 제한한다.

- 무기: 공격력, 공격속도, 치명타, 치명타 피해, 상태이상 피해, 특정 계통/스킬 강화 등
- 방어구: 최대 체력, 방어력, 상태저항, 경직·넉백 저항 등
- 장신구: 마나, 마나회복, 이동속도, 스킬·유틸·조건부 효과 등

## 2. 동부 특수 단조술

동부 특수 동료의 보상은 `특수 단조술`로 한다.

- 기존 랜덤 옵션은 유지한다.
- 장비에 **단조술 전용 특수 옵션 1개를 추가**한다.
- 장비당 단조 옵션은 최대 1개만 유지한다.
- 다시 단조하면 일반 옵션은 건드리지 않고 기존 단조 옵션만 교체한다.
- 단조 옵션은 단순 수치 증가보다 무기/장비 운용감을 바꾸는 효과를 우선한다.

예시:

- 공격 범위 증가
- 무기 사거리 증가
- 투사체 관통/속도 변화
- 회피 거리 증가
- 경직 저항 강화
- 방패 방어 범위 확대
- 특정 시전/공격 동작 보조

## 3. 전설 장비의 이름과 형태

전설 장비는 무기 종류의 틀에 억지로 맞추지 않는다.

- `대검`, `특대검`, `특대도끼` 같은 분류보다 **누가 사용할 수 있는 장비인가**를 우선한다.
- 예: 크루세이더 전용, 바바리안 전용, 매화바바 전용, 네크로맨서 전용 등.
- 묠니르처럼 기존 무기군과 정확히 맞지 않는 신화 무기도 해당 캐릭터가 자연스럽게 사용할 수 있으면 허용한다.
- 필요하면 내부적으로만 애니메이션 프로파일을 두고, 플레이어에게는 무기 형태 분류를 강하게 노출하지 않는다.

신화·전승에 실제 고유명이 있는 장비는 원명을 사용하는 방향을 우선한다.

- 서부: 중세 유럽 영웅·기사 전승권
- 북부: 노르드·게르만 신화권
- 중부: 이집트 신화 중심 검토
- 동부/남부: 지역 신화권에 맞춰 추후 확정

해당 역할에 적합한 전승 장비가 없을 때만 게임 고유 전설 장비를 창작한다.

## 4. 전설 장비 획득 방식

전설 장비를 완제품으로 낮은 확률 드랍시키는 구조보다, **보스 전용 소재를 획득해 가공·제작하는 방식**을 기본으로 한다.

흐름:

```text
보스 처치
→ 보스 고유 소재 획득
→ 해당 소재의 고정 제작 목록 확인
→ 지역 희귀 재료와 함께 가공
→ 원하는 전설 장비 제작
```

전설 장비는 지역 퀘스트 또는 보스전과 연결한다.

## 5. 보스 소재별 제작 한계

**모든 보스가 모든 직업의 전설 장비를 제공하지 않는다.**

보스마다 그 보스의 신화, 외형, 능력에서 자연스럽게 파생되는 **제작 가능 장비 풀을 제한**한다.

권장 규모:

- 필드 보스: 전설 제작품 약 2~3개
- 지역 보스: 전설 제작품 약 3~4개

예시:

```text
타이탄의 핵
→ 거신 무기
→ 거신 갑주
→ 거인의 심장 장신구
```

이 방식의 목적:

- 6직업 × 모든 지역 전설 장비를 강제로 만드는 콘텐츠 폭증 방지
- 보스별 고유 정체성 강화
- 플레이어가 원하는 장비를 주는 보스를 선택해 파밍하게 함
- 불필요한 전설 장비 양산 방지

## 6. 반복 파밍 강도

전설 장비 하나를 얻기 위해 같은 보스를 장시간 반복 토벌하게 만들지 않는다.

- 기본 목표는 **보스 1~2회 클리어 정도면 전설 장비 하나를 제작할 수 있는 수준**.
- 실제 획득 빈도는 보스 소재 드랍량·드랍률·추가 재료 요구량으로 조정한다.
- 희귀함은 수십 번 반복 요구보다, 보스 자체의 난도·퀘스트·제작 선택에서 만든다.

## 7. 현재 핵심 원칙

- 장비 등급: 일반 / 고급 / 희귀 / 전설
- 등급 상승 시 기본 능력치와 랜덤 옵션 수·질 증가
- 랜덤 옵션은 장비 부위별 제한 풀 사용
- 전설에는 고정 고유효과 추가
- 동부 특수 단조술은 기존 옵션을 유지한 채 전용 특수 옵션 1개 추가
- 전설 장비는 무기 형태보다 직업/캐릭터 사용 가능 여부 중심으로 분류
- 신화·전승의 실존 고유 장비명은 가능하면 원명 사용
- 전설 장비는 보스 고유 소재를 가공해 제작
- 보스별 제작 가능 장비 수를 제한해 콘텐츠 수를 통제
- 모든 직업이 모든 보스에서 자기 전설 장비를 얻을 필요 없음
- 필드 보스보다 지역 보스가 조금 더 넓은 제작 풀을 가질 수 있음
- 반복 파밍은 1~2회 클리어를 기본 목표로 조정
