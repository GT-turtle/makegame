# 기본 6직업 무기 없는 Body Idle / Run 제작 브리프

> Unity 3D 구현과 원화·모델링 작업에서 공통으로 사용하는 1차 제작 기준.  
> 상위 기준: `docs/ART_DIRECTION.md`, `docs/CHARACTER_VISUALS.md`, `docs/ANIMATION_DIRECTION.md`

## 1. 이번 작업 범위

이번 단계에서는 기본 6직업의 **무기 없는 캐릭터 Body**만 제작한다.

- 크루세이더
- 네크로맨서
- 바바리안
- 추적자
- 매화
- 아크메이지

각 직업별 산출물:

1. Full-body Idle 대표 자세
2. Full-body Run 대표 키포즈
3. 정면
4. 후면
5. 좌측 45도
6. 우측 45도
7. 동일 축척 실루엣 비교

무기·방패·검집·스태프·활은 이번 이미지에서 제외한다. 다만 향후 무기 장착 자세와 손 위치를 고려해 손·팔·어깨·척추·골반의 기본 자세를 설계한다.

## 2. Unity 구현 기준

- 엔진: Unity
- 캐릭터: 3D 모델
- 골격: Humanoid Rig
- 이동: 캐릭터 Transform을 360도 회전
- 애니메이션: 직업별 Full-body Idle / Run
- 상·하체 애니메이션 분리 방식은 기본 설계에서 사용하지 않음
- 무기 모델은 별도 Prefab으로 제작
- 무기 장착 후 손 위치는 Socket + Two Bone IK로 미세 조정
- IK로 전체 자세를 억지로 변경하지 않음
- 좌측 45도와 우측 45도에서 의상 비대칭, 머리, 허리띠, 손 위치가 명확히 구분되어야 함

## 3. 무기와 캐릭터 Body 분리

무기를 무시하는 것이 아니라 **캐릭터 Body 디자인과 무기 디자인을 별도 에셋으로 제작**한다.

```text
Character Body
- 얼굴
- 헤어
- 의상
- 체형
- Humanoid Rig
- Full-body Animation

Weapon Prefab
- Mesh
- Main Grip
- Secondary Grip
- VFX Socket
- 장착 Socket 정보
```

이후 기본·전승·전설 무기를 같은 캐릭터에 교체 장착한다.

## 4. 직업별 Body 방향

### 크루세이더

- 40대 서유럽계 남성
- 금발 장발, 짧은 수염 허용
- 노련한 정통 서양 기사
- 넓은 어깨와 중장갑 체형
- Idle: 낮고 안정적인 무게중심, 전방을 지키는 자세
- Run: 짧고 묵직한 보폭, 상체 흔들림 적음
- 실제 장착 예정: 바스타드 소드 + 중대형 카이트/히터 방패

### 네크로맨서

- 30대 동유럽계 남성
- 짙은 중간 길이 머리, 뒤로 넘기고 일부 앞머리가 자연스럽게 내려옴
- 멀쩡하고 지적인 성숙한 인간, 타락 표현 최소화
- 길고 마른 전투 마도사 체형
- Idle: 한쪽 손은 향후 롱소드를 들 수 있게 낮게, 반대손은 강령술을 쓸 수 있게 열림
- Run: 검술과 주문을 모두 사용할 수 있는 균형 잡힌 전투 달리기
- 실제 장착 예정: 한손 롱소드 + 빈손 강령술

### 바바리안

- 20대 북유럽계 남성
- 거친 숏컷, 수염 없거나 매우 짧음
- 기본 6직업 중 가장 크고 육중한 체격
- 상의 없음 또는 모피·가죽을 일부 두른 형태
- Idle: 넓은 스탠스, 큰 흉곽과 어깨 강조
- Run: 큰 보폭, 전신 관성, 판타지 액션답게 속도감 유지
- 현재 시안보다 몸집을 더 크게 표현
- 실제 장착 예정: 양손 대형 도끼

### 추적자

- 20대 후반~30대 초반 여성
- 피부톤이 비교적 밝은 동남아시아계 판타지 인상
- 실전용 높은 포니테일 또는 단단히 땋아 묶은 머리
- 몸에 붙는 천/가죽 전투복 + 부분 경갑
- Idle: 낮고 민첩한 사냥꾼 자세
- Run: 숲·습지에서 빠르게 방향을 바꿀 수 있는 가벼운 보폭
- 실제 장착 예정: 몽골계 복합궁에서 영감을 받은 짧은 곡궁
- 이동 사격용 Aim/Strafe Run은 이후 별도 Full-body 세트로 제작

### 매화

- 20대 동아시아계 남성
- 젊고 자신감 있으며 장난기·배짱이 느껴지는 성인 검객
- 긴 머리를 낮게 묶거나 반묶음
- 한·중·일 혼합 판타지 복장
- Idle: 가볍고 절제된 검술 스탠스
- Run: 빠르고 조용한 발놀림, 상체 중심이 크게 흔들리지 않음
- 전투 중에는 향후 한손에 검, 반대손에 검집을 든다
- 기본 공격마다 발도·납도를 반복하지 않음
- 특정 발도 기술에서만 검집을 이용한 순간 발도 사용

### 아크메이지

- 20대 후반~30대 초반 북유럽계 여성
- 긴 장발
- 챙 넓은 마법사 모자 + 긴 망토 + 허리띠
- 허리 아래 천과 소지품은 달리기·회피에 방해되지 않도록 고정
- Idle: 지적이고 자신감 있는 정통 마법사 자세
- Run: 지나치게 느리거나 떠다니지 않고 실제로 달리는 동작
- 망토와 머리카락은 큰 실루엣을 만들되 물리 흔들림은 절제
- 실제 장착 예정: 긴 스태프

## 5. 전승 예외

기본 6직업 Body 세트를 우선 공유하되 아래는 별도 제작한다.

- 정령 바바리안: 완전한 늑대형 별도 Rig와 애니메이션
- 검술/매화 바바리안: 양손 특대검용 전용 Full-body Idle / Run / Attack
- 중갑 추적자/대궁병: 대궁·저격 태세용 전용 Full-body Idle / Run / Aim

## 6. 시각 검수 기준

- 무기를 빼도 여섯 직업이 체형·헤어·복장·자세만으로 구분되어야 함
- 바바리안은 다른 남성보다 확실히 크고 넓어야 함
- 좌측 45도와 우측 45도가 동일하거나 거울처럼 뭉개져 보이면 안 됨
- 추적자와 아크메이지의 여성 실루엣은 서로 명확히 달라야 함
- 매화는 미소년이 아니라 단련된 성인 남성으로 보여야 함
- 크루세이더의 금발 장발이 중장갑 외곽선에 묻히지 않아야 함
- 네크로맨서는 전형적인 지팡이 법사나 언데드처럼 보여서는 안 됨
- 실제 아이소메트릭 전투 크기로 축소해도 각 직업의 큰 형태가 남아야 함
