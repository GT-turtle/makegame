# 배낭공방: 폐역 원정 — 프로토타입 설계서

## 한 문장

영구적으로 발전하는 영지에서 직업과 가방을 설계하고, 여러 생태 지역이 이어진 광활한 폐역에서 설계도와 희귀 재료를 가져오는 모바일 개척 RPG.

## 목표 경험

플레이어는 강한 아이템 하나를 찾는 것보다 여러 아이템의 작동 조건을 이해하고 연결해 자신만의 엔진을 완성한다. 초반에는 검과 방패가 따로 작동하지만, 원정이 진행되면 이동·공격·피격·처치가 서로 다른 장치를 연쇄적으로 움직인다.

핵심 감정은 다음 세 가지다.

1. 처음에는 복잡해 보이던 규칙이 이해되는 순간
2. 가방 배치 하나로 전투 결과가 달라지는 순간
3. 원정의 결과가 공방과 세계에 영구적으로 남는 만족감

## 핵심 순환

영지 생산 → 직업·특성 선택 → 가방 배치 → 광역 원정 → 전투·환경 대응 → 설계도·희귀 재료 확보 → 귀환 → 무작위 품질 장비 제작 → 더 위험한 지역 개척

## 현재 구현된 시스템

### 원정

- 31×31 절차 생성 연속 필드와 9×9 추적 카메라
- 시야와 탐색 완료 영역 구분
- 황동 황야, 포자 저습지, 검은 철로, 감시자의 분지
- 측량탑 세 곳을 재가동한 뒤 최종 감시자와 전투
- 보급함의 지역 재료·직업 설계도, 적의 재료 드롭, 회복·보관 야영지
- 황야의 작열, 늪의 독성, 철로의 혹한, 분지의 오염 압력
- 직업·출신·장비·연금 기술을 자유롭게 겹치는 다중 대응
- 모든 행동 이후 자동 저장

### 전투

- 네 방향 이동 및 인접 공격
- 적이 공격 전 `!`로 의도를 예고
- 예고 후 거리를 벌리면 적의 공격이 빗나감
- 중독, 화상, 감전, 방어, 회피
- 기사, 야만인, 메카닉, 무인의 서로 다른 자원 획득과 고유 기술
- 기술을 사용할수록 영구적으로 오르는 숙련도
- 최근 발동 아이템과 계산 결과를 전투 기록에 표시

### 가방

- 기본 5×4, 연구 후 5×5
- 직사각형 및 L자 아이템
- 선택 → 빈 칸 배치 방식의 터치 조작
- 회전과 보관함 이동
- 모든 배치 아이템의 조건부 발동
- 실제 효과가 발생하는 연결만 강조
- 전투 중 배치 변경은 한 턴 소비

### 영지와 지속 성장

- 집사장, 벌목꾼, 광부, 대장장이 고용
- 원정 턴에 연동되는 목재·광석 자동 생산과 철괴 제련
- 원정 설계도와 재료를 이용한 장비 제작
- 제작마다 달라지는 품질과 1~2개의 무작위 옵션
- 연구한 설계도와 가방 확장 영구 저장
- 최고 측량탑 기록과 승리 횟수 저장
- 실패해도 장비·연구·설계도·개척 결과 유지
- 실패 시 미보관 고철과 재료는 절반, 설계도는 전부 회수
- 시즌, 행동력, 현실 시간 제작 대기 없음

## 설계 원칙

- 아이템은 수치보다 새로운 작동 규칙을 제공한다.
- 무작위 변수는 플레이어를 속이지 않고 대응할 정보를 준다.
- 영구 성장은 선택지를 늘리되, 단순 능력치 누적으로 전투를 무력화하지 않는다.
- 실패는 긴장감을 주지만 오랜 노력을 삭제하지 않는다.
- 한 화면에는 한 가지 판단만 둔다. 지도와 가방을 동시에 축소해 보여주지 않는다.
- Android 세로 화면에서 한 손으로 주요 조작이 가능해야 한다.
