# 배낭공방 프로젝트 방향 기록

## 대화에서 출발한 핵심 취향

- 녹픽던처럼 화면의 칸을 눌러 이동하고, 적과 환경에 턴 단위로 대응한다.
- 한 층씩 내려가는 던전보다 넓은 지역을 직접 탐험하는 감각을 우선한다.
- 가방에 배치한 장비는 하나만 선택하는 것이 아니라 각자 효과가 모두 작동하고, 인접 배치로 조합된다.
- 귀한 재료는 가방에서 즉석 합성하지 않는다. 모험에서 가져와 영지의 대장간에서 장비로 만든다.
- 전투만 반복하지 않고 영지를 건설하고 일꾼을 고용해 벌목, 채광, 제련, 제작을 자동화한다.
- 특정 정답 장비만 강요하지 않고 직업, 특성, 룬, 연금, 환경 장비를 섞어 여러 해법을 만든다.
- 장기적으로는 디아블로식 장비 파밍과 환세취호전식 기술 숙련 성장을 함께 지향한다.

## 확정된 게임 구조

게임의 중심 순환은 다음과 같다.

1. 영지에서 직업, 출신 특성, 가방 배치와 생산 인력을 정한다.
2. 월드맵에서 `내 영지`, `사막`, `설산`처럼 독립된 지역을 선택한다.
3. 선택한 지역 안에서 터치 이동 기반 턴제 탐험을 진행한다.
4. 적의 예고 공격, 지역 환경 압력, 보스 조건에 가방 조합과 직업 기술로 대응한다.
5. 설계도와 희귀 재료를 확보해 영지로 귀환한다.
6. 일꾼의 자동 생산물과 원정 재료를 결합해 품질과 옵션이 다른 장비를 제작한다.
7. 새 장비와 숙련된 기술로 더 위험한 지역에 도전한다.

## 전투와 성장

### 직업

- 기사: 방어와 태세, 오염·한기 대응
- 야만인: 피해와 분노, 강한 근접 파쇄
- 메카닉: 이동으로 동력을 모으고 포탑과 장치를 운용
- 무인: 내공, 회피, 회복과 환경 압력 순환

룬과 연금술은 특정 직업에 묶지 않고 모든 직업이 활용하는 공용 계통이다.

### 환경 변수

- 사막: 작열
- 설산: 혹한
- 포자 지대: 독성
- 고대 기계 지대: 오염

직업의 기본 적응, 출신 특성, 가방 장비, 무작위 장비 옵션, 연금 회복약과 직업 기술을 겹쳐 대응할 수 있다.

### 장기 성장

- 직업 기술은 사용할수록 숙련 경험치를 얻는다.
- 보급함과 보스는 완제품 대신 설계도와 희귀 재료를 중심으로 보상한다.
- 대장간 제작품은 품질과 무작위 옵션이 달라 같은 설계도도 다시 제작할 이유가 있다.
- 실패해도 설계도와 영구 성장 기록은 남고, 미보관 자원만 일부 잃는다.

## 구조 개편 전 프로토타입 v0.3.0

- Android 세로 화면용 APK
- 31×31 절차 생성 필드와 9×9 추적 카메라
- 밝혀진 칸 터치 이동, 장거리 자동 이동, 새 적 발견 시 한 턴 경계 후 이동 재개
- 전체 지도와 원거리 목적지 지정
- 4개 직업, 4개 출신 특성, 직업 자원과 고유 기술 숙련
- 가방 5×4/5×5 배치, 회전, 인접 조합과 동시 발동
- 작열·독성·혹한·오염 압력과 복수 대응 방식
- 희귀 재료, 설계도, 야영지 보관, 보스 보상
- 집사장, 벌목꾼, 광부, 대장장이와 원정 턴 연동 자동 생산
- 설계도 제작, 품질, 무작위 장비 옵션
- v1~v3 저장 데이터 마이그레이션

## 이번 구조 개편

기존에는 하나의 31×31 필드 안에 사막, 늪, 철로, 분지가 동시에 있었다. 앞으로는 월드맵에서 지역을 선택하고 각 지역이 독립된 턴제 맵과 규칙을 갖는 구조로 바꾼다.

- 내 영지: 안전한 순찰과 벌목장·채석장 같은 생산 거점 확인
- 유리모래 사막: 작열 압력, 태양 파편, 사막형 적
- 백설령 설산: 혹한 압력, 흑철 파편, 설산형 적
- 후속 지역은 동일한 지역 템플릿에 지형색, 적 목록, 환경 압력, 보상, 목표만 추가해 확장
- v0.4.0부터 지역별 방문·승리·최고 측량 기록을 따로 저장하고 v1~v4 저장을 호환

## 후속 우선순위

1. 지역마다 다른 보스 패턴과 복합 페널티
2. 영지 건물의 실제 배치와 생산 연결선
3. 직업별 기술 3개 이상과 숙련 분기
4. 지역별 설계도·장비 옵션·룬·연금 제조법 확대
5. 폴더블 펼침 화면용 지도/정보 2단 UI
6. 캐릭터, 적, 영지와 지역의 정식 픽셀 아트
