# 동료 트리거·개인 이벤트 설계 기준

> ChatGPT와 Claude가 공유하는 동료 이벤트 설계 기준. 호감도 수치를 직접 노출하지 않고, 플레이어가 활동을 통해 자연스럽게 개인 이벤트를 발견하는 방향을 우선한다.

## 1. 핵심 원칙

- **호감도 수치를 UI에 표시하지 않는다.**
- 동료별로 고유한 `Trigger` 조건을 가진다.
- 트리거는 플레이어가 그 동료의 성격·직업·배경을 보면 **대략 어떤 활동을 해야 할지 예상할 수 있는 방향**으로 설계한다.
- 단순히 숨겨진 숫자만 쌓는 호감도 시스템은 사용하지 않는다.
- 조건이 충족되면 동료가 먼저 반응하거나 이벤트가 발생한다.
- 보상은 일반 전투 보상보다 희소성이 높은 것으로 둔다.

## 2. 트리거 후보

동료마다 아래 조건 중 일부를 조합한다.

- 특정 지역 점령
- 특정 지역 방문
- 특정 보스 처치
- 특정 스탯 수치 도달
- 특정 능력/성취 수준 도달
- 특정 직업 또는 전승 상태
- 특정 동료와 함께 원정
- 특정 장비·재료·유물 보유
- 특정 종류의 전투/수성전/제작/탐사 반복
- 특정 장소·유적·던전 발견

트리거는 동료의 정체성과 연결되어야 한다.

예시:

- 고고학자 → 중부 유적 탐사, 고대 장치 발견, 특정 지역 점령
- 대장장이 → 희귀 광석 확보, 제작 횟수, 특정 보스 소재 획득
- 사냥꾼 → 거대 몬스터 처치, 특정 생태 지역 탐사
- 기사 → 수성전 승리, 방어 관련 성취
- 검객/매화계 동료 → 검술 성취, 동부 특정 장소 방문

## 3. 이벤트 결과

트리거 충족 시 다음 중 하나 또는 복수의 결과를 제공할 수 있다.

- 희귀 아이템
- 전용 장비
- 설계도
- 장인 소개 또는 영지 파견
- 추가 제작법
- 특정 지역·던전·장소 관련 정보
- 개인 이벤트 연쇄 시작
- 동료 전용 전투/탐사 보너스 해금

보상은 반드시 전투력 수치만 올리는 형태일 필요는 없다. 제작, 탐사, 영지, 전설 장비 등 다른 시스템과 연결할 수 있다.

## 4. 플레이어가 예상할 수 있는 트리거

트리거는 완전히 랜덤하거나 의미 없는 숨은 조건으로 만들지 않는다.

좋은 예:

- 고고학자와 함께 중부 유적을 반복 탐사한다.
- 대장장이 동료가 있는데 희귀 광석을 다량 확보한다.
- 기사 동료와 함께 수성전에 여러 번 승리한다.

나쁜 예:

- 아무 설명 없이 이동 횟수 137회 도달
- 관계없는 지역에서 특정 아이템 7개를 소지
- 동료 성격과 상관없는 숨은 카운터 충족

플레이어가 정확한 숫자를 몰라도 `이 동료와 이런 활동을 계속하면 뭔가 있을 것 같다`고 추론할 수 있어야 한다.

## 5. 수집형 게임화 방지

- 동료 도감이나 최대 동료 수를 표시하지 않는 현재 방향을 유지한다.
- 동료를 모두 모으는 것을 명시적인 목표로 만들지 않는다.
- 특정 동료 이벤트를 못 봤다고 경고하거나 미획득 슬롯을 보여주지 않는다.
- 동료 개인 이벤트는 발견형 콘텐츠로 취급한다.

## 6. 지역별 특수 동료

- **북부·남부·동부·서부·중부에 각각 1명의 특수 동료를 둔다.**
- 총 5명의 특수 동료는 일반 동료와 달리 지역 공략 순서와 특정 사건에 영향을 받는다.
- 플레이어에게 `특수 동료`, `지역당 1명`, `총 5명`이라는 사실을 UI로 알리지 않는다.
- 특수 동료의 존재와 최대 숫자는 숨겨진 발견 요소로 취급한다.

### 현재 확정/검토 중인 특수 동료와 보상

| 지역 | 특수 동료 | 구조 시 효과 |
|---|---|---|
| 서부 | 타락하기 직전의 성기사 | 플레이어 패시브 **`흑마법의 비밀`** 해금. 플레이어 **1회 부활**. 정확한 발동 단위·회복량은 추후 조정 |
| 북부 | 마탑 설계자 | **마탑 건축 가능**, 마법 연구 기능/효율 향상 |
| 남부 | 떠돌이 연금술사 | **특수 연금술 해금**. 무기에 특수 효과를 부여·강화하는 기능도 이 축에 포함 |
| 동부 | 쫓기던 대장장이 | 전설 장비 이후에도 가치가 남는 **동부 고유 무기 강화 기능**을 해금하는 방향. 구체 옵션은 미확정 |
| 중부 | 고고학자 | **골렘 설계도 해금** |

### 동부 대장장이 보상 방향

- 단순 `특수 무기 제작`은 전설 장비를 얻은 뒤 가치가 퇴색할 수 있으므로 폐기 방향.
- 화상·빙결·연쇄·흡혈 같은 **상태/속성 특수효과 부여·강화는 남부 특수 연금술에 배정**한다.
- 동부 대장장이는 연금술과 겹치지 않는 **무기 자체의 기예·제련·장인 각인 계열**을 담당하는 방향을 검토한다.
- 후보 예시: `장인 각인/무기술 각인`을 통해 쳐내기, 약점 공격, 연격 마무리, 경직/파괴 등 **물리적 운용 특성**을 변형·강화.
- 위 후보는 **아직 확정안이 아니며**, 동부 지역 정체성과 전설 장비 이후의 지속 가치를 동시에 만족하는 옵션을 추가 검토한다.

### 상호배타 등장 원칙

- 특정 특수 동료를 먼저 구조·영입하면, 다른 지역의 일부 특수 동료는 더 이상 영입 가능한 상태로 등장하지 않을 수 있다.
- 별도의 세계 시계나 턴 카운터는 사용하지 않는다.
- 배타 조건은 `어떤 특수 동료를 먼저 확보했는가`, `어떤 지역 사건을 먼저 해결했는가` 같은 사건 플래그로 처리한다.
- 영입 기회를 잃은 인물을 플레이어에게 `놓친 동료`라고 알려주지 않는다.
- 해당 장소를 나중에 방문하면 동료 대신 익명의 환경 이벤트로 대체할 수 있다.

예시:

```text
중부를 먼저 공략
→ 고고학자 구조·영입
→ 다른 지역 특수 동료의 구조 이벤트 비활성화
→ 해당 장소를 나중에 방문
→ "시체 한 구가 있다." 같은 익명 이벤트 발생
```

- 시체 이벤트에서 이름, 직업, 원래 동료였다는 사실을 직접 알려주지 않는다.
- 다른 플레이에서 다른 순서로 진행했을 때 동일 인물이 살아 있는 모습으로 등장할 수 있다.
- 이 차이를 게임이 설명하지 않아도 된다. 플레이어가 반복 플레이나 커뮤니티를 통해 자연스럽게 발견하는 것을 허용한다.

## 7. 다른 확정 방향과의 연결

- FTL의 조건부 이벤트처럼 `동료 + 지역 + 상태/성취` 조합으로 특수 이벤트를 열 수 있다.
- 지역 점령 순서와 동료 구성에 따라 일부 사건이 달라질 수 있다.
- Hades형 정령 축복은 별도 시스템으로 두되, 동료 트리거 이벤트와 충돌하지 않게 한다.
- 향후 동료 수가 증가해도 공통 호감도 UI를 추가하지 않고, 각 동료의 고유 트리거와 개인 사건을 확장하는 방향을 우선한다.

## 8. 구현 권장 데이터 구조

일반 동료 이벤트 예시:

```js
companionEvent = {
  id: "archaeologist_ruin_memory",
  companionId: "archaeologist",
  conditions: [
    { type: "regionCaptured", regionId: "central" },
    { type: "companionAchievement", stat: "archaeology", min: 3 }
  ],
  eventId: "central_ruin_memory",
  rewards: [
    { type: "blueprint", id: "ancient_golem_core" }
  ],
  once: true
};
```

특수 동료 상태 예시:

```js
specialCompanion = {
  id: "central_archaeologist",
  regionId: "central",
  state: "available", // available | recruited | unavailable | dead
  exclusiveGroup: "regional_special_companions"
};
```

구현 시 조건문을 캐릭터 코드에 직접 박지 말고 데이터 기반으로 관리한다.

## 9. 현재 확정 사항

- 호감도 숫자 표시 없음
- 동료별 고유 트리거 사용
- 트리거 방향은 플레이어가 동료의 성격·배경을 통해 예상 가능해야 함
- 트리거 예: 지역 점령, 특정 스탯/성취 도달, 보스 처치, 탐사, 제작, 수성전 등
- 보상 예: 희귀 아이템, 설계도, 장인 파견, 개인 이벤트
- 동료 도감 없음
- 최대 동료 수 비공개
- 향후 동료 수는 지속적으로 추가 가능
- 지역당 1명의 특수 동료를 둠
- 특수 동료의 존재·총수는 플레이어에게 공개하지 않음
- 특수 동료는 공략 순서/사건 플래그에 따라 상호배타적으로 등장 가능
- 영입 불가 상태가 된 특수 동료는 이름 없는 시체·흔적 등 환경 이벤트로 대체 가능
- 별도 세계 시계나 턴제 진행 시스템은 사용하지 않음
- 서부 성기사: `흑마법의 비밀` 1회 부활 패시브 방향
- 북부 마탑 설계자: 마탑 건축/마법 연구 강화
- 남부 떠돌이 연금술사: 특수 연금술 및 무기 특수효과 부여·강화
- 중부 고고학자: 골렘 설계도
- 동부 대장장이: 전설 장비 이후에도 유효한 동부 고유 무기 강화 기능을 검토 중
