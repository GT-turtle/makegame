# 동료 트리거·개인 이벤트 설계 기준

> ChatGPT와 Claude가 공유하는 동료 이벤트 설계 기준. 호감도 수치를 직접 노출하지 않고, 플레이어가 활동을 통해 자연스럽게 개인 이벤트를 발견하는 방향을 우선한다.

## 1. 핵심 원칙

- **호감도 수치를 UI에 표시하지 않는다.**
- 동료별로 고유한 `Trigger` 조건을 가진다.
- 트리거는 플레이어가 그 동료의 성격·직업·배경을 보면 **대략 어떤 활동을 해야 할지 예상할 수 있는 방향**으로 설계한다.
- 단순히 숨겨진 숫자만 쌓는 호감도 시스템은 사용하지 않는다.
- 조건이 충족되면 동료가 먼저 반응하거나 이벤트가 발생한다.
- 보상은 일반 전투 보상보다 희소성이 높은 것으로 둔다.

## 2. 트리거 후보

동료마다 아래 조건 중 일부를 조합한다.

- 특정 지역 점령
- 특정 지역 방문
- 특정 보스 처치
- 특정 스탯 수치 도달
- 특정 능력/성취 수준 도달
- 특정 직업 또는 전승 상태
- 특정 동료와 함께 원정
- 특정 장비·재료·유물 보유
- 특정 종류의 전투/수성전/제작/탐사 반복
- 특정 장소·유적·던전 발견

트리거는 동료의 정체성과 연결되어야 한다.

예시:

- 고고학자 → 중부 유적 탐사, 고대 장치 발견, 특정 지역 점령
- 대장장이 → 희귀 광석 확보, 제작 횟수, 특정 보스 소재 획득
- 사냥꾼 → 거대 몬스터 처치, 특정 생태 지역 탐사
- 기사 → 수성전 승리, 방어 관련 성취
- 검객/매화계 동료 → 검술 성취, 동부 특정 장소 방문

## 3. 이벤트 결과

트리거 충족 시 다음 중 하나 또는 복수의 결과를 제공할 수 있다.

- 희귀 아이템
- 전용 장비
- 설계도
- 장인 소개 또는 영지 파견
- 추가 제작법
- 특정 지역·던전·장소 관련 정보
- 개인 이벤트 연쇄 시작
- 동료 전용 전투/탐사 보너스 해금

보상은 반드시 전투력 수치만 올리는 형태일 필요는 없다. 제작, 탐사, 영지, 전설 장비 등 다른 시스템과 연결할 수 있다.

## 4. 플레이어가 예상할 수 있는 트리거

트리거는 완전히 랜덤하거나 의미 없는 숨은 조건으로 만들지 않는다.

좋은 예:

- 고고학자와 함께 중부 유적을 반복 탐사한다.
- 대장장이 동료가 있는데 희귀 광석을 다량 확보한다.
- 기사 동료와 함께 수성전에 여러 번 승리한다.

나쁜 예:

- 아무 설명 없이 이동 횟수 137회 도달
- 관계없는 지역에서 특정 아이템 7개를 소지
- 동료 성격과 상관없는 숨은 카운터 충족

플레이어가 정확한 숫자를 몰라도 `이 동료와 이런 활동을 계속하면 뭔가 있을 것 같다`고 추론할 수 있어야 한다.

## 5. 수집형 게임화 방지

- 동료 도감이나 최대 동료 수를 표시하지 않는다.
- 동료를 모두 모으는 것을 명시적인 목표로 만들지 않는다.
- 특정 동료 이벤트를 못 봤다고 경고하거나 미획득 슬롯을 보여주지 않는다.
- 동료 개인 이벤트는 발견형 콘텐츠로 취급한다.
- 향후 동료 수는 계속 추가할 수 있다.

## 6. 지역별 특수 동료

- **북부·남부·동부·서부·중부에 각각 1명의 특수 동료를 둔다.**
- 플레이어에게 `특수 동료`, `지역당 1명`, `총 5명`이라는 사실을 UI로 알리지 않는다.
- 특수 동료의 존재와 최대 숫자는 숨겨진 발견 요소로 취급한다.
- 특수 동료 보상은 단순 수치 보너스보다 **플레이 메타 자체를 바꾸는 기능 해금**을 우선한다.

### 현재 확정된 특수 동료와 보상

| 지역 | 특수 동료 | 구조 시 효과 |
|---|---|---|
| 서부 | 타락하기 직전의 성기사 | 플레이어 패시브 **`흑마법의 비밀`** 해금. 전투 중 **1회 부활** 계열 효과. 정확한 발동 단위와 회복량은 추후 조정 |
| 북부 | 마탑 설계자 | **마탑 건축 + 마법 스크롤 제작/보급 시스템 해금** |
| 남부 | 떠돌이 주술사/연금 계열 인물(명칭 추후 확정) | **주술 각인 해금**. 이후 특수 룬이 드랍되며, 사용 시 플레이어의 상태이상 관련 능력이 영구 누적 강화 |
| 동부 | 쫓기던 대장장이 | **특수 단조술 해금**. 장비의 **특수 옵션 변경** 가능 |
| 중부 | 고고학자 | **고대 골렘 복원/운용 해금**. 골렘을 플레이어와 별개로 단독 토벌에 파견 가능 |

### 북부 — 마법 스크롤

- 마탑 설계자 구조 후 마탑을 건축하면 전투용 마법 스크롤을 제작할 수 있다.
- 한 원정에는 **스크롤 한 종류만 선택**해 가져갈 수 있다.
- 선택한 스크롤은 **최대 5장**까지 휴대 가능하다.
- 직업 스킬과 별개의 강력한 소모성 전투 수단으로 취급한다.

현재 확정/검토 중인 스크롤:

- **블리자드**: 넓은 범위에 지속 냉기 피해와 빙결/제어 효과.
- **메테오**: 지정 범위에 적당한 크기의 화염구가 **무작위 위치로 연속 낙하**.
- **낙뢰**: 단발성 강력한 낙뢰. 기존 연쇄 번개 스킬과 겹치지 않게 **연쇄 효과 없이 단발**로 설계. `브레이크` 시스템과 연결하는 안은 검토 중.

### 남부 — 주술 각인 / 특수 룬

- 특수 동료 구조 후 남부 계열 **특수 룬 드랍이 해금**된다.
- 특수 룬은 일반 룬보다 낮은 드랍률을 가진다.
- 장착형이 아니라 **1회 사용 시 플레이어 자체 스탯이 영구 상승하는 소모형 성장 자원**이다.
- 여러 종류로 쪼개지 않고 **특수 룬 1종에 두 효과를 통합**한다.

특수 룬 사용 시:

1. **CC/상태이상 지속시간 감소** 영구 증가
   - 많이 사용할수록 효과가 커진다.
   - 최대 효율은 **99%**까지 접근하며 100%에는 도달하지 않는다.
   - 성장식은 로그/점근형 비선형 곡선을 사용해 고강화까지 계속 의미가 남게 한다.
2. **플레이어가 가하는 상태이상 피해 증가** 영구 상승
   - 독·화상·출혈·부패 등 상태이상 기반 빌드의 장기 성장축.
   - CC 저항과 같은 룬에 묶어 플레이어가 자신의 빌드에 맞는 만큼 파밍하도록 한다.

### 동부 — 특수 단조술

- 단순 특수 무기 제작은 전설 장비 획득 후 가치가 퇴색하므로 사용하지 않는다.
- 대장장이 구조 후 **장비 특수 옵션 변경** 기능을 해금한다.
- 장비 티어가 올라가도 계속 사용 가능한 후반 장비 세팅 시스템으로 취급한다.
- 구체적인 옵션 풀·변경 비용·랜덤/선택 방식은 추후 확정한다.

### 중부 — 고대 골렘 자동 토벌

- 고고학자 구조 후 고대 골렘 설계/복원 기능을 해금한다.
- 골렘은 플레이어 파티의 추가 전투원이 아니라 **혼자 토벌을 수행하는 독립 병기**다.
- 골렘 운용으로 플레이어가 직접 수행하는 토벌과 별개로 **병렬 토벌 수와 총 토벌 횟수/던전 소화량을 증가**시킬 수 있다.
- 구체적인 파견 가능 던전 범위, 제작·수리 비용, 성공 판정은 추후 확정한다.

### 서부 — 흑마법의 비밀

- 타락 직전 성기사를 구출하면 플레이어가 그의 금지된 지식을 통해 **`흑마법의 비밀`** 패시브를 얻는다.
- 핵심 효과는 **1회 부활**.
- 전투/원정 단위, 부활 체력 비율 등 세부 수치는 추후 밸런싱한다.

### 상호배타 등장 원칙

- 특정 특수 동료를 먼저 구조·영입하면, 다른 지역의 일부 특수 동료는 더 이상 영입 가능한 상태로 등장하지 않을 수 있다.
- 별도의 세계 시계나 턴 카운터는 사용하지 않는다.
- 배타 조건은 `어떤 특수 동료를 먼저 확보했는가`, `어떤 지역 사건을 먼저 해결했는가` 같은 사건 플래그로 처리한다.
- 영입 기회를 잃은 인물을 플레이어에게 `놓친 동료`라고 알려주지 않는다.
- 해당 장소를 나중에 방문하면 동료 대신 익명의 환경 이벤트로 대체할 수 있다.

예시:

```text
중부를 먼저 공략
→ 고고학자 구조·영입
→ 다른 지역 특수 동료의 구조 이벤트 비활성화 가능
→ 해당 장소를 나중에 방문
→ "시체 한 구가 있다." 같은 익명 이벤트 발생
```

- 시체 이벤트에서 이름, 직업, 원래 동료였다는 사실을 직접 알려주지 않는다.
- 다른 플레이에서 다른 순서로 진행했을 때 동일 인물이 살아 있는 모습으로 등장할 수 있다.
- 이 차이를 게임이 직접 설명하지 않아도 된다.

## 7. 다른 확정 방향과의 연결

- FTL의 조건부 이벤트처럼 `동료 + 지역 + 상태/성취` 조합으로 특수 이벤트를 열 수 있다.
- 지역 점령 순서와 동료 구성에 따라 일부 사건이 달라질 수 있다.
- Hades형 정령 축복은 별도 시스템으로 두되, 동료 트리거 이벤트와 충돌하지 않게 한다.
- 향후 동료 수가 증가해도 공통 호감도 UI를 추가하지 않고, 각 동료의 고유 트리거와 개인 사건을 확장하는 방향을 우선한다.

## 8. 구현 권장 데이터 구조

일반 동료 이벤트 예시:

```js
companionEvent = {
  id: "archaeologist_ruin_memory",
  companionId: "archaeologist",
  conditions: [
    { type: "regionCaptured", regionId: "central" },
    { type: "companionAchievement", stat: "archaeology", min: 3 }
  ],
  eventId: "central_ruin_memory",
  rewards: [
    { type: "blueprint", id: "ancient_golem_core" }
  ],
  once: true
};
```

특수 동료 상태 예시:

```js
specialCompanion = {
  id: "central_archaeologist",
  regionId: "central",
  state: "available", // available | recruited | unavailable | dead
  exclusiveGroup: "regional_special_companions"
};
```

구현 시 조건문을 캐릭터 코드에 직접 박지 말고 데이터 기반으로 관리한다.

## 9. 브레이크 시스템 메모

- 북부 `낙뢰` 스크롤과의 연계를 검토한다.
- 아직 확정 시스템은 아니다.
- 구현한다면 우두머리/정예에게 `breakGauge`를 두고 특정 공격이 게이지를 깎아 0에서 짧은 무력화 상태를 만드는 단순 구조부터 시작한다.
- 별도의 부위 파괴, 자세 단계, 몬스터별 복잡한 브레이크 패턴까지 처음부터 넣지 않는다.

## 10. 현재 확정 사항

- 호감도 숫자 표시 없음
- 동료별 고유 트리거 사용
- 트리거 방향은 플레이어가 동료의 성격·배경을 통해 예상 가능해야 함
- 동료 도감 없음 / 최대 동료 수 비공개
- 지역당 1명의 숨겨진 특수 동료
- 특수 동료는 공략 순서/사건 플래그에 따라 상호배타적으로 등장 가능
- 영입 불가가 된 인물을 `놓친 동료`라고 알려주지 않음
- 별도 세계 시계나 턴제 진행 시스템 없음
- 서부: `흑마법의 비밀` 1회 부활
- 북부: 마탑 + 전투용 마법 스크롤, 원정당 1종/최대 5장
- 남부: 주술 각인 + 영구 성장 특수 룬(CC 지속 감소 최대 99% 접근 + 상태이상 피해 증가)
- 동부: 특수 단조술 + 장비 특수 옵션 변경
- 중부: 고대 골렘 단독 자동 토벌로 병렬 토벌 능력 증가
