# 배낭공방: 내 영지 — Unity 3D 애니메이션·방향 처리 기준

> 캐릭터 움직임, 무기 부착, 전투 애니메이션 구현 시 ChatGPT와 Claude가 공유하는 최신 기준 문서.

## 1. 구현 방식 확정

- 엔진은 **Unity** 기준으로 설계한다.
- 캐릭터는 **3D 모델 + Humanoid 스켈레탈 애니메이션** 방식으로 제작한다.
- 카메라는 **고정 아이소메트릭/쿼터뷰**를 기본으로 한다.
- 2D 8방향 스프라이트는 별도로 제작하지 않는다.
- 캐릭터 모델 자체를 360도 회전시켜 방향을 표현한다.
- 기본 직업과 전승은 얼굴·체형·기본 골격을 최대한 공유하고, 복장·무기·이펙트와 필요한 전용 동작으로 차별화한다.
- 평상시에는 로스트아크처럼 캐릭터를 작게 보여 다수전과 공격 범위를 우선한다.
- 보스 등장·페이즈 전환·궁극기·완전 변신 때만 제한적으로 카메라 확대/구도 변화를 사용한다.

## 2. 캐릭터와 무기 에셋은 분리한다

무기 디자인은 캐릭터 바디와 별도 에셋으로 제작한다.

```text
Character Body
- 얼굴
- 머리
- 의상
- Humanoid Rig
- Full-body Animation

Weapon Prefab
- 실제 무기 Mesh
- Main Grip Point
- Sub Grip Point (필요 시)
- VFX Socket
- Sheath/Back Socket 정보
```

원칙:
- 캐릭터 바디 원화/모델링과 무기 원화/모델링을 별도로 진행한다.
- 기본·전승·전설 무기를 같은 캐릭터에 교체 장착할 수 있어야 한다.
- 무기는 Unity에서 손/등/허리 등의 Socket에 Prefab으로 부착한다.
- 무기 모델이 바뀌어도 같은 무기 계열이면 Full-body Animation을 최대한 재사용한다.
- 전설급 무기도 동일 계열 기본 모션을 우선 재사용하되, 전투 기믹이 달라질 경우 전용 동작을 추가할 수 있다.

## 3. 상·하체 애니메이션 분리는 기본 방식으로 사용하지 않는다

초기 제안이었던 `Base Locomotion + UpperBody Weapon Layer` 방식은 기본 설계에서 제외한다.

이유:
- 직업마다 무게중심, 골반, 척추, 어깨 방향이 다르다.
- 상체만 덮어쓰면 검·방패·활·양손무기 자세에서 몸 전체의 연결이 부자연스러워질 수 있다.
- 이 게임은 직업별 전투 실루엣을 중요하게 보기 때문에 자세 왜곡을 줄이는 것을 우선한다.

따라서:
- **직업별 Full-body Idle/Run/Attack**을 기본으로 한다.
- 손 위치가 무기 Grip에서 약간 어긋날 때만 Unity Animation Rigging / Two Bone IK 등으로 미세 보정한다.
- IK는 자세를 새로 만드는 용도가 아니라 손이 무기 손잡이에서 미끄러지지 않도록 보정하는 용도로 제한한다.

## 4. 방향 처리

- 이동 방향은 카메라 기준 입력 벡터를 월드 방향으로 변환한다.
- 캐릭터는 이동/공격 방향으로 전신이 회전한다.
- 즉시 45도 단위로 꺾는 방식이 아니라 짧은 회전 보간을 사용한다.
- 3D 모델이므로 정면/후면/좌우/대각을 별도 그림으로 만들지 않는다.
- 애니메이션은 동일하게 재생하고 캐릭터 Transform 회전으로 모든 방향을 표현한다.
- 컨셉 시트에서는 대각선 좌우를 명확히 구분해 3D 실루엣과 장비 간섭을 검증한다.

## 5. 기본 애니메이션 세트

각 기본 직업은 최소 다음 Full-body 동작을 가진다.

- Idle
- Walk / Run
- Basic Attack
- Skill Cast / Skill Attack
- Dodge
- Hit Reaction
- Death

현재 첫 제작 우선순위는 **기본 6직업의 무기 없는 Body Idle / Run**이다.

무기 없는 Body 시트를 먼저 만드는 이유:
- 캐릭터 체형·의상·방향 실루엣 검증
- Humanoid Rig와 보폭 검증
- 무기 디자인을 별도 과정에서 충분히 발전시킬 수 있음
- 기본/전승/전설 무기 교체에 유리

단, 무기 없이 만든다는 것은 무기 사용 자세를 무시한다는 뜻이 아니다. Full-body 애니메이션 설계 시 해당 직업이 어떤 무기 계열을 사용하는지는 반드시 고려한다.

## 6. 직업별 움직임 기준

### 크루세이더
- 40대 남성, 서부 정통 기사.
- 바스타드 소드 + 중대형 카이트/히터 방패 계열을 전제로 자세를 설계한다.
- 낮고 안정적인 무게중심.
- 중장갑 때문에 보폭은 비교적 짧고 묵직하다.
- Run에서도 몸이 과도하게 위아래로 튀지 않는다.
- 실제 무기 장착 후에는 검과 방패를 몸 가까이 유지하는 전용 Full-body 자세 사용.

### 네크로맨서
- 30대 동유럽계 성숙한 남성.
- 한손 롱소드 + 반대손 강령술.
- 지팡이형 법사 모션을 사용하지 않는다.
- 이동은 검을 사용할 수 있는 전투 마도사 체형으로 설계한다.
- 주문 시 빈손과 상체가 크게 열리지만 골반/하체도 함께 반응하는 Full-body 동작을 사용한다.

### 바바리안
- 20대 북유럽계 남성.
- 여섯 직업 중 가장 크고 무거운 체형.
- 기본 무기는 양손 대형 도끼.
- 바디 Idle/Run 단계에서도 어깨 폭, 큰 보폭, 전신 관성이 두드러지게 한다.
- **최종 바디 디자인은 현재 시안보다 체격을 더 크게** 잡는다.
- 실제 도끼 장착 Run에서는 도끼를 양손으로 든 상태로 달리는 Full-body 동작을 사용한다.
- 판타지 액션 특성상 실제 무기 중량에 따른 현실적 속도 저하는 크게 강조하지 않아도 된다.

### 추적자
- 밝은 피부톤의 동남아 판타지 인상, 여성.
- 몽골계 복합궁에서 영감을 받은 짧은 곡궁을 사용한다.
- 바디 Run은 가볍고 빠르며 숲/습지 이동에 맞는 낮은 무게중심.
- 일반 이동은 Full-body 애니메이션.
- 실제 이동 사격은 공격 구현 단계에서 별도의 `Aim/Strafe Run` Full-body 세트를 추가한다.
- 기본 설계에서는 상하체 분리 조준을 사용하지 않는다.

### 매화
- 20대 동아시아계 남성.
- 한·중·일 혼합 판타지 도검술.
- 전투 진입 시 **검을 이미 뽑은 상태**를 기본으로 한다.
- 기본 공격마다 발도/납도를 반복하지 않는다.
- 전투 중:
  - 한손: 검
  - 반대손: **검집을 직접 들고 사용**
- 검집을 허리에 고정하지 않아도 되므로 달리기 중 검집/의상 충돌 문제를 줄일 수 있다.
- 검집은 방어, 밀치기, 자세 보조, 특정 발도 스킬의 준비 동작에 활용 가능하다.
- 특정 발도 기술에서는 일시적으로 검을 검집에 넣었다가 순간 발도한 뒤 다시 전투 자세로 돌아간다.
- Run 시 검과 검집 모두 몸 가까이 유지하며 가볍고 절제된 발놀림 사용.

### 아크메이지
- 20대 후반~30대 초반 북유럽계 여성.
- 긴 스태프, 넓은 챙 모자, 긴 망토.
- 바디 Run은 마법사이지만 지나치게 느리거나 떠다니는 느낌은 피한다.
- 달리기와 회피에 방해되지 않도록 허리 아래 천과 장비를 정리한다.
- 스태프 장착 후에는 전용 Full-body 자세를 사용한다.
- 캐스팅은 팔만 움직이지 않고 가슴·척추·골반까지 포함한 큰 제스처로 설계한다.

## 7. 전승 애니메이션 규칙

- 같은 무기 계열과 비슷한 역할이면 기본 직업 Full-body 애니메이션을 최대한 재사용한다.
- 무기 형태나 전투 원리가 크게 달라지면 별도 Full-body 애니메이션을 추가한다.
- 전승 외형은 얼굴과 기본 체형을 유지하지만 복장·무기·VFX와 일부 동작을 변경한다.

### 정령 바바리안
- 완전한 늑대형 변신.
- 인간 Humanoid Rig를 재사용하지 않는다.
- 별도 늑대 Rig 및 Idle/Run/Attack/Dodge/Hit/Death 필요.

### 검술/매화 바바리안
- 바바리안 체형 유지.
- 양손 **특대검** 사용.
- 기본 양손도끼 모션과 자세가 크게 달라지므로 **전용 Full-body Idle/Run/Attack 세트**를 추가한다.
- 큰 특대검을 양손으로 운용한다.
- 단순 난타가 아니라 특대검의 무게·관성·중심 이동을 이용한 절제된 대검술.

### 중갑 추적자 / 대궁병
- 기본 추적자와 무기 크기·저격 자세·이동 성격이 크게 다르다.
- **전용 Full-body Idle/Run/Aim 세트**를 추가한다.
- 저격/포격 태세에서는 이동 방식 자체가 달라질 수 있다.

현재 기준에서 완전 별도 이동 세트를 우선 요구하는 인간형 전승은 `검술 바바리안`과 `중갑 추적자`다.

## 8. 손·무기 연결과 IK

Unity에서 무기는 독립 Prefab으로 관리한다.

권장 Socket:
- RightHandWeaponSocket
- LeftHandWeaponSocket
- BackWeaponSocket
- HipWeaponSocket
- Optional SheathSocket

양손 무기:
- 주손은 기본 WeaponSocket에 고정.
- 보조손은 무기 Prefab 내부 `SecondaryGrip` Transform을 기준으로 Two Bone IK 보정.

한손 무기:
- 손 소켓에 직접 장착.

매화:
- 검과 검집을 각각 독립 Prefab으로 관리 가능.
- 전투 중 양손에 각각 장착.
- 발도 스킬에서 검/검집 Attachment 또는 Animation Event를 이용해 상태 전환.

원칙:
- IK로 골반/척추/어깨 전체 자세를 억지로 고치지 않는다.
- 손목/팔꿈치의 작은 위치 오차만 보정한다.

## 9. 무기 디자인 제작 순서

캐릭터 Body와 무기는 별도 디자인한다.

1. 기본 6직업 Body Idle/Run 확정
2. 기본 무기 디자인 시트
   - 크루세이더: 바스타드 소드 + 중대형 방패
   - 네크로맨서: 롱소드
   - 바바리안: 양손 대형 도끼
   - 추적자: 짧은 복합궁
   - 매화: 외날검 + 검집
   - 아크메이지: 긴 스태프
3. Weapon Socket / Grip 위치 정의
4. Body + Weapon 결합 자세 검증
5. 전승 무기 디자인
6. 지역별 전설급 무기 디자인

전설급 무기는 별도 외형뿐 아니라 스킬 궤적, VFX, 일부 모션/판정 변화까지 고려할 수 있다.

## 10. 카메라 연출

평상시:
- 캐릭터는 작게 보여 다수전과 범위를 우선.
- 플레이어 + 자동 동료 최대 2명 + 다수 적 + 위험 범위를 동시에 읽을 수 있어야 한다.

카메라 변화 허용:
- 보스 등장
- 보스 페이즈 전환
- 대형 보스 패턴
- 플레이어 궁극기
- 완전 변신
- 전투 승리

원칙:
- 일반 스킬마다 과도한 줌/회전을 사용하지 않는다.
- 궁극기 연출 종료 직후 기본 전투 카메라로 빠르게 복귀한다.

## 11. 현재 우선 제작 순서

1. **무기 없는 기본 6직업 Body Idle**
2. **무기 없는 기본 6직업 Body Run**
3. 방향/대각선에서 체형·복장 실루엣 검증
4. 기본 무기 6계열 독립 디자인
5. Weapon Socket / Grip 연결 테스트
6. 무기 장착 Full-body Idle/Run
7. Basic Attack
8. Dodge / Hit / Death
9. 직업별 대표 스킬
10. 검술 바바리안·중갑 추적자 전용 이동 세트
11. 정령 바바리안 늑대 Rig
12. 궁극기/보스 카메라 연출

## 12. 구현 시 주의

- 렌더링 FPS와 전투 판정 타이밍은 분리한다.
- 스킬 판정은 Animation Clip 자체만을 원본 데이터로 사용하지 않는다.
- startup / active / recovery 데이터와 Animation Event를 동기화한다.
- 모바일에서 캐릭터가 작게 보이므로 손가락·표정보다 실루엣과 큰 자세 변화를 우선한다.
- 긴 망토·머리카락·검집 등의 물리 흔들림은 전투 가독성을 해치지 않는 수준으로 제한한다.
- 무기 에셋과 Body 에셋은 분리하되, 애니메이션 제작 단계에서는 해당 무기의 사용 자세를 항상 고려한다.
