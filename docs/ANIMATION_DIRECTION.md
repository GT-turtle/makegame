# 배낭공방: 내 영지 — 3D 애니메이션·방향 처리 기준

> 캐릭터 움직임과 전투 애니메이션 구현 시 ChatGPT와 Claude가 공유하는 기준 문서.

## 1. 구현 방식 확정

- 캐릭터는 **3D 모델 + 스켈레탈 애니메이션** 방식으로 제작한다.
- 카메라는 **고정 아이소메트릭/쿼터뷰**를 기본으로 한다.
- 2D 8방향 스프라이트를 별도로 제작하지 않는다.
- 캐릭터 모델 자체를 360도 회전시켜 방향을 표현하고, 애니메이션은 골격 기반으로 재사용한다.
- 기본 직업과 전승은 얼굴·체형·기본 골격을 최대한 공유하고, 복장·무기·이펙트와 일부 전용 동작으로 차별화한다.

## 2. 방향 처리

- 이동 방향은 월드 기준이 아니라 **카메라 기준 입력 벡터**로 변환한다.
- 일반 근접 직업은 이동 방향 또는 현재 타겟 방향으로 캐릭터 전신이 회전한다.
- 원거리 직업은 필요하면 하체 이동 방향과 상체 조준 방향을 분리한다.
- 추적자는 이동 사격이 핵심이므로 **상·하체 분리 조준**을 우선 적용한다.
- 캐릭터는 즉시 방향 전환하지 않고 짧은 회전 보간을 사용한다.

## 3. 기본 애니메이션 세트

각 기본 직업은 최소 다음 동작을 가진다.

- Idle
- Walk / Run
- Basic Attack
- Skill Cast / Skill Attack
- Dodge
- Hit Reaction
- Death

직업별 전용 동작은 이 공통 세트 위에 추가한다.

## 4. 직업별 움직임 기준

### 크루세이더
- 낮고 안정적인 무게중심.
- 중대형 카이트/히터 방패를 전방에 두고 짧고 묵직한 보폭.
- 바스타드 소드 공격은 상체와 골반 회전을 함께 사용.
- 방패가 캐릭터 전체를 가리지 않게 유지.

### 네크로맨서
- 한손 롱소드 + 반대손 강령술.
- 이동 중 검은 낮게 두고 빈손은 자유롭게 유지.
- 강령 주문 시 빈손과 상체가 크게 열리며, 검은 방어적 위치에 남을 수 있다.
- 지팡이를 사용하는 일반 법사 모션을 재사용하지 않는다.

### 바바리안
- 양손 대형 도끼.
- 큰 보폭과 전신 회전을 사용하며 무기 관성을 강조한다.
- 공격 준비 동작은 크고 읽기 쉽게, 타격 순간은 빠르게 가속.
- 회수 동작과 후딜에서 무기의 무게가 느껴져야 한다.

### 추적자
- 짧고 강한 복합궁.
- 이동 방향과 사격 방향을 분리할 수 있게 한다.
- 달리면서 상체를 틀어 사격하는 동작이 가능해야 한다.
- 하체는 이동, 상체는 타겟 조준을 담당하는 레이어드 애니메이션을 권장한다.

### 매화
- 전투 진입 시 **검을 이미 뽑은 상태**를 기본으로 한다.
- 평상시 전투 Idle/Run에서도 검은 손에 들고 있으며 검집은 허리에 남는다.
- 기본 공격마다 매번 발도·납도를 반복하지 않는다.
- 발도는 전투 시작 연출, 특정 스킬, 전투 종료 연출, 궁극기 등 특별한 순간에만 사용 가능하다.
- 전투 중 검집은 실루엣 요소이자 일부 스킬의 보조 동작에 활용할 수 있다.
- 기본 검술은 빠른 연계와 절제된 발놀림을 중심으로 한다.

### 아크메이지
- 긴 스태프 사용.
- 이동 중 스태프는 한손 또는 양손으로 안정적으로 운용.
- 캐스팅은 상체·팔·스태프의 큰 제스처와 망토·머리카락의 보조 움직임으로 가독성 확보.
- 일반 캐스팅 중 하체 이동은 제한하되 완전 정지 여부는 스킬별로 결정한다.

## 5. 전승 애니메이션 규칙

- 같은 무기와 비슷한 역할은 기본 애니메이션을 최대한 공유한다.
- 무기 형태가 크게 달라지거나 전투 원리가 바뀌면 상체 또는 전체 공격 애니메이션을 교체한다.
- 단순 이펙트 교체만으로 부족한 스킬은 전용 모션을 추가한다.

### 정령 바바리안
- 궁극기 변신 후에는 완전한 늑대형 골격과 별도 애니메이션을 사용한다.
- 네발 이동, 도약, 할퀴기, 물어뜯기, 급회전이 필요하다.

### 검술/매화 바바리안
- 기본 바바리안 체형을 유지하지만 양손 특대검 전용 애니메이션을 사용한다.
- 도끼 모션을 그대로 재활용하지 않는다.
- 특대검의 무게와 관성을 살리되, 정교한 대검술이라는 인상이 나야 한다.

## 6. 카메라 연출

평상시:
- 캐릭터는 비교적 작게 보여 다수전과 공격 범위를 우선한다.
- 전장 정보와 텔레그래프를 가리지 않는다.

카메라 변화 허용:
- 보스 등장
- 보스 페이즈 전환
- 대형 보스 패턴
- 플레이어 궁극기
- 정령 바바리안 완전 변신
- 전투 승리 연출

원칙:
- 일반 스킬마다 과도한 줌·회전을 사용하지 않는다.
- 궁극기 카메라 연출 후 즉시 전투 가독성이 높은 기본 위치로 복귀한다.

## 7. 우선 제작 순서

1. 기본 6직업 공용 humanoid 골격 검증
2. 각 직업 Idle / Run
3. 각 직업 Basic Attack
4. Dodge / Hit / Death
5. 직업별 대표 스킬 1개
6. 추적자 상하체 분리 조준
7. 전승별 무기·모션 차이
8. 정령 바바리안 늑대형 별도 골격
9. 궁극기 카메라 연출

## 8. 구현 시 주의

- 렌더링 FPS와 전투 판정 타이밍은 분리한다.
- 애니메이션이 공격 판정의 유일한 원본이 되지 않도록 하고, 스킬 데이터의 startup / active / recovery와 동기화한다.
- 모바일에서 캐릭터가 작게 보이므로 손가락·표정 같은 미세 동작보다 실루엣과 큰 자세 변화를 우선한다.
- 긴 망토·머리카락·검집은 물리 흔들림을 과도하게 쓰지 말고 전투 가독성을 해치지 않게 제한한다.
