# 벤치마크 분석과 적용 원칙

## 목표

배낭공방은 한 게임을 복제하지 않는다. 터치형 필드 탐사, 실시간 부대 자동전투, 가방 조합, 영지 자동 생산, 보스 소재 제작, 지속 성장을 한 순환으로 묶는다.

`영지에서 준비 → 대륙 지역 선택 → 넓은 필드 탐사 → 좁은 던전의 실시간 부대 전투 → 희귀 재료 회수 → 주민과 시설이 생산·제작 → 더 어려운 지역에 도전`

## v0.5.0 적용 사항

1. 첫 화면을 영지 전경으로 바꾸고 영주관·고용소·룬 공방·대장간·창고·원정 성문을 직접 누르게 한다.
2. 각 시설은 한 가지 의사결정에 집중한다. 긴 대시보드를 스크롤하며 기능을 찾지 않는다.
3. 원정 성문에서 지역의 환경 발생량, 현재 직업·특성·가방의 대응량, 실제 증가량을 출정 전에 계산한다.
4. 지역별 목표와 핵심 재료·설계도 보상을 출정 전에 보여 목표 파밍을 가능하게 한다.
5. 가방, 일꾼, 연구, 제작과 지역 선택 기능은 기존 저장 데이터를 그대로 사용한다.

## 다음 적용 우선순위

1. 유닛 편성·교체·장비와 부상 회복

3. 가방 장비 효과를 개척자의 직접 행동과 개별 동료 AI에 전달
4. 필드 채집·야영·날씨와 환경 대응
5. 전투 발동 통계와 원정 종료 분석
