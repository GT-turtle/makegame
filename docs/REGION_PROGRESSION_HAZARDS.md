# 지역 환경 패널티·필드 진행 설계

> 지역 내부의 하위 필드를 순서대로 공략하면서, 앞 필드에서 얻은 장비·재료·세팅으로 다음 필드의 환경 위험에 대응하게 만드는 진행 구조.

## 1. 핵심 원칙

- 지역 환경 패널티는 단순한 장식용 디버프가 아니라 **지역 내부 진행을 반쯤 강제하는 장비·세팅 게이트**로 사용한다.
- 기본 흐름은 `하위 필드 공략 → 대응 아이템/재료 확보 → 세팅 변경 → 다음 필드 진입·공략`이다.
- 모든 지역을 완전히 막는 하드 게이트로 만들지는 않는다. 지역마다 압박 방식과 강제 정도를 다르게 한다.
- 단, 중부처럼 컨셉상 필요한 지역은 **내성 기준 미달 시 다음 필드 진입 불가** 같은 하드 게이트를 허용한다.
- 범용으로 모든 지역 패널티를 크게 줄이는 장비는 두지 않는다. 지역별 대응 장비를 준비해야 한다.
- 기존 `개척자의 목걸이`처럼 모든 지역 환경 패널티를 한 번에 낮추는 전설 장신구 컨셉은 폐기한다.
- 대응 장비는 주로 앞선 필드에서 얻은 재료·보스 부산물·제작품으로 마련한다.
- 구체적인 누적 속도, 내성 요구치, 피해량은 추후 밸런싱한다.

## 2. 지역별 환경 위험

### 북부 — 한기

- 환경 수치: `한기`
- 한기가 쌓일수록 **공격속도와 이동속도가 감소**한다.
- 일정 수준 이상 누적되면 **지속 냉기 피해**가 발생한다.
- 하위 필드에서 얻는 방한·한기 저항 장비로 누적 속도와 전투 페널티를 완화한다.
- 북부의 핵심은 `전투 성능 저하 → 누적 심화 시 지속 피해`다.

### 남부 — 독성·오염

- 환경 수치: `독성 / 오염` 계열을 현재 방향으로 유지한다.
- 지속 피해, 회복 방해, 독·부패 계열 상태이상과 연결한다.
- 깊은 필드로 갈수록 대응 장비·연금·상태이상 대응 세팅의 중요도가 올라간다.
- 세부 누적 규칙은 추후 확정한다.

### 동부 — 미정

- **현재 비워둔다.**
- 고산 저산소, 영적 간섭, 풍압 등 기존 제안은 확정하지 않는다.
- 동부의 영물·문파·산악 지형과 실제 플레이를 함께 고려해 별도 설계한다.

### 서부 — 저주

- 환경 수치: `저주`
- 서부를 깊게 탐사할수록 저주가 누적된다.
- 동료는 플레이어가 명령하는 구조가 아니라 **스스로 이동하고 대상을 선정해 싸우는 자동 동료**라는 기존 전투 구조를 유지한다.
- 저주가 한계치에 도달한 동료는 명령 불복종 같은 중간 단계를 거치지 않고 **적 진영으로 전환**한다.
- 적대화된 동료는 기존 자동 AI를 그대로 사용하되, 플레이어와 다른 동료를 적으로 인식해 공격한다.
- 저주 완화·정화 장비와 세팅으로 누적을 늦추거나 해소하게 한다.
- 영구적인 동료 손실 여부와 전투 종료 후 복귀 방식은 추후 확정한다.

### 중부 — 폭염

- 환경 수치: `폭염`
- 폭염이 누적되면 **화상 계열 지속 피해**가 발생하고 누적이 심해질수록 생존 압박이 커진다.
- 북부처럼 공격속도·이동속도를 떨어뜨리는 방식은 사용하지 않는다.
- 깊은 하위 필드는 일정 수준의 `내열` 또는 대응 세팅을 요구한다.
- 요구치를 충족하지 못하면 **다음 필드 진입 자체가 불가능**한 하드 게이트를 사용한다.
- 즉, 중부는 `앞 필드에서 내열 준비 → 다음 필드 진입 → 내부에서는 폭염·화상 누적 관리` 구조다.

## 3. 현재 지역별 차별화

| 지역 | 핵심 압박 | 진행 강제 방식 |
|---|---|---|
| 북부 | 한기 → 공속·이속 감소 → 지속 냉기 피해 | 대응 세팅이 없으면 전투가 급격히 불리해짐 |
| 남부 | 독성·오염 → 지속 피해·회복 방해 | 장기전과 상태이상 관리 압박 |
| 동부 | 미정 | 추후 설계 |
| 서부 | 저주 누적 → 자동 동료 적대화 | 동료 운용 자체가 무너질 수 있음 |
| 중부 | 폭염 → 화상 지속 피해 | 내열 기준 미달 시 다음 필드 진입 불가 |

## 4. 장비·장신구와의 관계

- 전설 방어구의 고유효과는 전투 방식을 바꾸는 효과를 우선한다.
- 환경 대응은 장신구, 일반·고급·희귀 장비 옵션, 연금 아이템 등 여러 경로에 분산할 수 있다.
- 단, `모든 지역 환경 패널티 50% 감소` 같은 범용 해답은 만들지 않는다.
- 플레이어가 다음 필드에 맞춰 장비나 세팅을 **반쯤 강제로 교체하게 만드는 것**이 목적이다.
- 지역별 대응 장신구와 세부 레시피는 각 지역 환경 수치가 더 확정된 뒤 다시 설계한다.
