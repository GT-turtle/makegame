# 보스 전투 설계 골격

> 개별 보스 패턴은 추후 천천히 확정한다. 현재 문서는 필드 보스와 지역 보스의 역할 차이, 페이즈 구조만 공통 기준으로 고정한다.

## 1. 필드 보스

- 필드 보스는 **기존 전투 규칙 안에서 매우 강한 적**으로 설계한다.
- 핵심은 강한 범위 공격, 돌진, 장판, 연속 공격 등 액션 대응이다.
- 플레이어는 기본적으로 `잘 피하고 잘 때리는 것`으로 공략할 수 있어야 한다.
- 별도의 고유 퍼즐/복잡한 기믹은 필수로 두지 않는다.
- **HP 50% 이하에서 기존 형태는 유지하고 새로운 패턴을 추가한다.**
- 즉 2페이즈라기보다 `패턴 확장/강화`에 가깝다.

## 2. 지역 보스

- 지역 보스는 필드 보스의 단순 상위호환이 아니라 **전장 규칙 자체를 바꾸는 고유 기믹 보스**로 설계한다.
- 각 지역 보스는 최소 1개의 대표 기믹을 가진다.
- **HP 50% 이하에서 명확한 2페이즈로 전환한다.**
- 2페이즈 진입 시 외형 또는 형태가 변화한다.
- 2페이즈에서는 단순히 패턴 하나를 추가하는 수준이 아니라, 기존 패턴의 성격과 전투 방식이 눈에 띄게 달라져야 한다.
- 다만 모든 보스를 완전히 다른 체형으로 변신시키지는 않는다. 아트/애니메이션 비용을 고려해 `갑옷 붕괴`, `핵 노출`, `폭주`, `변이`, `오라/기관 활성화` 같은 변화도 적극 활용한다.

## 3. 필드 보스와 지역 보스의 차이

```text
필드 보스
= 강한 액션 전투
= HP 50%에서 패턴 추가
= 기존 형태 유지

지역 보스
= 액션 + 고유 기믹
= HP 50%에서 2페이즈 시작
= 형태/외형 변화
= 전투 방식 자체가 달라짐
```

## 4. 북부 지역 보스 — 타이탄 (초기 골격)

- 타이탄은 `거대한 적을 어떻게 쓰러뜨릴 것인가`가 핵심 기믹이다.
- 단순히 본체 체력을 계속 깎는 구조보다 **팔/다리 등 특정 부위를 공략해 자세를 무너뜨리고 공격 기회를 만드는 구조**를 우선 검토한다.
- 자세가 무너지면 핵심부/약점이 노출되는 형태를 고려한다.
- 이 부위 공략은 현재로서는 **타이탄 전용 기믹**으로 보고, 공통 브레이크 시스템으로 확정하지 않는다.
- HP 50% 이하에서는 장갑 붕괴, 내부 핵 노출 등 2페이즈 형태 변화 방향을 우선 검토한다.
- 구체 공격 패턴과 수치는 추후 별도로 설계한다.

## 6. 현재 확정 요약

- 필드 보스: 강한 전투형 보스
- 필드 보스 HP 50%: 패턴 추가
- 지역 보스: 고유 기믹형 보스
- 지역 보스 HP 50%: 2페이즈 전환
- 지역 보스 2페이즈: 형태/외형 변화 + 전투 방식 변화
- 북부 타이탄: 부위 공략 → 자세 붕괴 → 약점 노출 방향
- 브레이크/그로기 공통 시스템: 보류
- 각 보스의 세부 패턴: **컨셉 확정됨 → `BOSS_PATTERN_CONCEPT.md`**

## 7. 그로기 (2026-08-26 구현)

§5에서 보류했던 브레이크/그로기를 도입했다. **보스에게만** 붙는 별도 게이지다.

| 항목 | 값 | 근거 |
|---|---|---|
| 임계 | 최대 체력의 55% 누적 피해 | 보스가 커져도 "몇 번 몰아쳐야 무너진다"가 일정하게 유지된다 |
| 지속 | 4초 | 무너진 동안 아무것도 못 한다(`actorDisabled`에 포함) |
| 받는 피해 | ×1.5 | 무너뜨린 보상 |
| 감쇠 | 1.2초간 안 맞으면 초당 5.5%씩 | 계속 피하기만 해서는 못 무너뜨린다 |
| 재발동 대기 | 12초 | 연속으로 무너지지 않게 |

**목적은 "쉬지 않고 몰아쳐서 무너뜨리는 구간"을 만드는 것**이다. 예고 장판은 피하라고
만든 것이지만, 피하기만 하면 게이지가 빠지므로 **피할 때와 붙을 때를 나누게** 된다.

무너지는 순간 시전 중이던 패턴과 깔아둔 예고를 함께 걷는다 — 보스가 쓰러졌는데
장판만 터지면 이상하다.

**잡몹에는 붙이지 않는다.** 어차피 금방 죽어서 게이지가 의미가 없고 화면만 복잡해진다.
